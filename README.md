# Stock Analyst — 智能个股分析与评级系统

面向 A 股（及港股）个人投资者的本地价值投资分析工具。零代码、一键启动、浏览器即用。

## 核心能力

- **自选股管理**：50 只上限，分组管理，A 股/港股混合
- **数据采集**：基于 akshare，覆盖 K线技术面 / 基本面 / 资金面 / 消息面，多数据源容错与自动补采
- **四维量化评分（v5.0 引擎）**：维度内子项级降级机制（字段缺失自动调权归一化），输出 0-100 综合分与五档评级
- **评级与建议**：中文投资建议文本、风险提示、评级变更追踪
- **价格建议**：ATR 动态网格价位、止盈止损、资金面信号转化、持仓状态机
- **每日报告**：定时/手动生成，Markdown 报告 + Excel 导出
- **回测中心**：评级有效性回测（T+1/T+5/T+20）、价格建议命中率验证（T+5/T+20）
- **自动优化**：基于回测准确率的规则化权重/阈值自动调参（安全阀回滚）
- **智能预警**：评级跨档、评分跌破阈值、主力资金连续净流出三类规则
- **指数评级**：大盘指数技术面评分

## 技术栈

| 类别 | 技术 |
|------|------|
| 语言 | Python 3.12+ |
| Web | Flask（单进程，本地 127.0.0.1:5000） |
| 数据源 | akshare（腾讯K线 / 新浪基本面 / 东财资金面 / 东财新闻） |
| 存储 | SQLite（WAL 模式） |
| 校验/处理 | pydantic v2 / pandas / numpy |
| 导出 | openpyxl（Excel） |

## 快速开始（Windows）

```bash
# 1. 安装依赖（Python 3.12+）
pip install -r requirements.txt

# 2. 一键启动（自动依赖检查/端口释放/健康检查）
start.bat
# 或直接运行
python app.py
```

启动后浏览器访问 **http://127.0.0.1:5000**

> 详细操作见 [用户使用说明.md](用户使用说明.md)


```
├── blueprints/         # API 路由（9 个业务域蓝图）
```

## 数据源说明

- K线：腾讯财经；基本面：新浪财经；资金面：东方财富（失败自动降级新浪/估算兜底）；新闻：东方财富
- 北向资金数据源已于 2024-08-16 停更（港交所政策），相关因子已降权
- 港股资金面数据源稳定性弱于 A 股，缺失时引擎自动降级
