## 0. 结论速览（先给答案）

**总答案：不支持「根据情绪交易」新增任何机制。** 五类情绪代理在当前库内数据
（回测窗口约 50 个交易日、670 条 A股真实评级样本）的检验结果：

| # | 代理 | 总体分化（T+5 上涨占比） | 评级档内增量 | 判定 |
|---|---|---|---|---|
| S1 | 新闻情绪 | **显著反向**：负面 58%（21/36）vs 正面 42%（132/318），+17pp | 最大仅 7.7pp（<15pp 门槛） | **已被 021BC 充分计价，维持现状** |
| S2 | 主力/超大单 | 弱：大幅流入 50% vs 大幅流出 43%（+7pp） | 仅「建议减仓」档 33pp/28pp（格 B 级），持有观望档反向 | 单档不稳 → **观察项** |
| S3 | 散户情绪 | 中小单口径=主力镜像（恒等式）；股东户数「集中=收集」**未获支持**（弱反向） | 无 | **叙述≠事实，透明告知** |
| S4 | 杠杆情绪 | 融资余额升 34%（45/132）vs 降 49%（106/218），**14.5pp 差一线达标**；三档方向一致 | 推荐买入档 22.4pp（格 B 级） | **观察项之首**，样本升级后复核 |
| S5 | 市场热度 | 换手率**字段失活不可检验**；量比缩量 48% vs 温和放量 30%（+19pp）但跨档跨带方向翻转 | 有格达标但方向不稳 | 换手率移交数据质量项；量比**观察项** |

四条关键含义：

1. **新闻情绪有预测力，但已被吃干**：总体反向分化（正面=已定价噪音）与 021BC
   归因一致；但同一评级档内部最大只剩 7.7pp——021BC 非对称映射+降权已吸收该信息。
   **再动权重/映射无增量价值**（R7+RED_LINES §6 已登记域，本轮不动，且证据也不支持动）。
2. **「真金白银」的资金情绪暂无一条同时满足**「两侧 n≥20、差 ≥15pp、跨档方向稳定」
   三条的展示门槛——杠杆情绪（S4）方向三档一致但总体差 14.5pp 差一线、档内格 B 级；
   最接近但**宁缺毋滥，本轮不做展示**，列观察项之首按月复核。
3. **操盘手卡的资金叙述是叙事不是已检验事实**：「筹码集中（户数降）=有人在收集」
   在本样本未获支持（集中桶 T+5 40%/均 −2.5%，反而弱于分散桶 47%/均 −0.8%）；
   「融资余额增加=杠杆追涨盘（不稳定）」倒是方向获得一致支持（观察项之首的佐证）。
   本轮不改 `capital_narrative` 代码——无证据不改文案，如实告知用户即为本轮交付。
4. **用户自身情绪（行为面）系统已重兵设防**：止损无条件最高层（021BR 分域不对称）、
   评级迟滞 ±3（021AG）、位置分化防追高（020R-48/021BU）、T+1 锁/二次确认（R16）、
   盘中口径标注（021BT）。58 笔流水的描述统计（摊薄加仓 64%、止损后再入场 6 次且
   再入价全部更低）为 **C 级样本，不构成任何新增行为机制的证据**——不做补强。

## 2. 分层检验证据（完整数字见查询存档）

存档：`docs/reports/021bw_sentiment_query_a_20260924.md`（+`.json`）、
`021bw_sentiment_query_hk_20260924.md`、`021bw_sentiment_query_all_20260924.md`。
口径：全部代理 **as-of 评级日**（只用当时可得信息，无未来函数）；T+5=return_1w、
T+20=return_1m；「上涨%」=后续收益>0 占比，「超额」=alpha>0 占比；
样本分级 021BU 同款（A≥30 / B 20~29 带 ⚠ / C<20 仅 INFO）；
成对分化门槛：**两侧各 n≥20 且差 ≥15pp**（比 021BU 的 ≥10/带更严，桶对照是本批核心结论）。

### E-S1 新闻情绪——「有预测力，但已被 021BC 吃干」

| 桶 | T+5 | T+20 |
|---|---|---|
| 正面(>0.1) | 42%（132/318）·均 −1.4% | 29%（91）·均 −3.3% |
| 中性(±0.1) | 45%（21/47） | INFO(n=12) |
| 负面(<−0.1) | **58%（21/36）·均 +0.9%** | INFO(n=13) |

- 成对分化：负面 vs 正面 **+17pp**（两侧 A 级，达标）——与 021BC 归因
  （消息面四维唯一负相关 −0.098、正面情绪=已定价噪音）完全同向。
- **增量对照**：评级档内最大分化仅 7.7pp（持有观望：中性 46% vs 正面 38%），
  远低于 15pp 门槛；消息面分带内（50-70 带：正面 41% vs 中性 60%）方向还翻转。
  → **新闻情绪的信息已被评级（021BC 后）充分计价，无残差增量**。
- 结构性问题（观察）：词典法正面/负面词覆盖不对称 → 样本正面:负面=318:36，
  「负面」桶实为罕见事件标签；正面桶的 42% 里还叠加了港股 T+20 的 75%（跨市场禁止合并）。

### E-S2 主力/超大单情绪——总体弱、单档强但跨档不稳

| 桶（5日累计） | T+5 | 建议减仓档内 | 持有观望档内 |
|---|---|---|---|
| 大幅流入(≥2千万) | 50%（39/78） | **76%（19/25）⚠偏小** | 36%（12/33） |
| 大幅流出(≤−2千万) | 43%（130/304） | 43%（46/107） | 41%（58/141） |

- 超大单口径同型：建议减仓档内 净买 71%（17/24 ⚠）vs 净卖 43%（49/115），+28pp。
- **判定：不支持展示**。「减仓档+主力大幅流入→后续反而最可能上涨」只在一个档出现、
  高桶格 B 级、持有观望档内方向反向（36% vs 41%）——单档强分化更可能是
  「减仓档对强势资金股过严」的档位现象（与 021BU「低位减仓错杀」同族），
  而非可复用的情绪因子。列观察项，与 021BU ④合并跟踪。

### E-S3 散户情绪——两个口径，一个退化的、一个反向的

1. **中小单口径（5日净向）机械退化**：单行恒等式 main+medium+small≡0 →
   散户净买 ≡ 主力净流出，S3a 与 S2a 是同一信息的正反面；
   2×2 组合（capital_narrative 的「吸筹/派发」四象限）只剩 2 格非空。
   **中小单不构成独立散户情绪源**——这是数据结构结论，与样本量无关。
2. **股东户数口径（180 日新鲜度守卫）**：

| 桶 | T+5 | T+20 |
|---|---|---|
| 户数增幅≥3%（分散） | **47%（75/161）·均 −0.8%** | 47%（45） |
| 户数稳定(±3%内) | 36%（38/106） | 29%（31） |
| 户数降幅≥3%（集中） | 40%（27/68）·**均 −2.5%（最差）** | INFO(n=14) |

   - 操盘手卡叙述「户数降=筹码向少数人集中（有人在收集）」→ 检验**未获支持**
     （集中桶上涨占比与平均收益均不占优，方向甚至相反，但桶差 7~11pp < 15pp，
     只能说「未支持」，不能说「显著反向」）。
   - 顺带：评分面读户数**无 staleness 守卫**（见 §4 O5-②）。

### E-S4 杠杆情绪——观察项之首（方向三档一致，差一线不达标）

| 桶（融资余额5日变化） | T+5 | 推荐买入档内 | 持有观望档内 | 建议减仓档内 |
|---|---|---|---|---|
| 升(>+0.5%) | **34%（45/132）** | 28%（8/29 ⚠） | 30%（20/67） | 39%（12/31） |
| 降(<−0.5%) | 49%（106/218） | 50%（13/26 ⚠） | 43%（39/90） | 52%（50/97） |

- 总体差 **14.5pp**（距 15pp 门槛一线），两侧均 A 级；**三档方向全部一致**
  （升比降低 22.4 / 13.4 / 12.8pp），资金面 50-70 带内更烈（升 5% ⚠ vs 降 39%）。
- 与 capital_narrative「融资余额增加=杠杆追涨盘（不稳定）」方向一致——
  这条叙述是目前唯一获得方向性佐证的资金话术。
- **判定：仍不做展示**（未达门槛+档内格 B/C 级），但按月复核；
  若档内格升至 A 级且总体差 ≥15pp 保持，再按 §4 O2 的展示设计落地。

### E-S5 市场热度——一个死字段、一个不稳信号

- **换手率：字段失活**，窗口内恒 0（详见 §1），0 对齐样本 → **不可检验**。
  顺带成为本批最有行动价值的数据质量发现（采集链 turnover 断供，见 §4 O5-①）。
- **量比**（当日量/前5日均量）：总体 缩量 48%（78/161）vs 温和放量 30%（18/61），
  **+19pp 达标**；但档内/带内方向翻转——推荐买入档内 缩量 58% vs 平量 22%（+35.5pp），
  建议减仓档内却 平量 56% vs 缩量 42%（−14pp），技术面三个分带两正一负。
  → **方向跨层不稳定，不做展示，列观察项**。

### E-HK 港股——全部门槛外 + 方向与 A股相反

140 样本无一档内分化达标；总体成对分化虽有（散户净买 61% vs 净卖 36%，+25pp 等），
但**方向与 A股相反**（A股散户净买=主力流出镜像→后续更差；港股散户净买→后续更好），
且档内增量为零、样本止于 2026-09-07（021BU 遗留的港股回测链路问题）。
→ **港股情绪展示全部暂缓**（R20 A/H 独立；跨市场数字严禁互推——本批实证了为什么）。

## 3. 用户自身情绪（行为面）盘点

### 3.1 系统已有的行为守护（偏差 → 机制映射）

| 行为偏差 | 已有守护机制 | 锚点 |
|---|---|---|
| 不认错/损失厌恶（扛单） | **止损无条件最高层**：纪律 > 评级 > 阶段的分域不对称层级 | 021BR `build_operations_matrix` / `_scan_stop_discipline` 置顶 |
| 边界抖动下的情绪化换挡 | 评级迟滞 ±3 分带（首次评级豁免） | 021AG `rating_hysteresis` |
| 追高/FOMO | 位置分位分带 + 成对分化警示（低位 90% vs 高位 42%） | 020R-48 `_calc_pos_and_dd20` / 021BU `position_note_for` |
| 冲动改账（篡改成本/删除流水） | T+1 流水锁 / 成本修正 ±30% 二次确认 / 24h 冷却 / 5 万二次验证 | R16 config 风控阈值 |
| 盘中情绪化操作 | 盘中触线提示一律带「盘中口径，以收盘确认为准」+ 收盘确认口径零改动 | 021BT `intraday_patrol` |
| 报告迎合用户情绪 | `generate_advice` 冻结（扩展只能后处理） | B24 / R13 |

**评估结论：行为守护机制面已按「分域+层级+迟滞+位置」成型，与行为金融教科书
清单（损失厌恶/追涨/过度自信/锚定/处置效应）逐项有对应。**
`trade_records` 58 笔描述统计（§3.2）不构成任何新增机制的证据门槛。

### 3.2 行为描述统计（C 级，仅描述不作依据；成本=历史买入 VWAP 近似）

- 摊薄加仓（买价低于此前买入均价）：**25/39 笔（64%）**——左侧加仓是主要买入形态；
- 买入位置（近 60 日分位）：高位区(≥0.7) 仅 3/39（8%）、低位区(≤0.3) 25 笔——
  **追高行为实际很少发生**（位置分化防追高的输入侧压力不大）；
- 卖出后 30 日内再入场：6 次，**再入价全部更低**——「卖后再低位接回」，
  均价改善方向，无「止损后立即追回」形态；
- 浮亏卖出（卖价<买入 VWAP）：10/19（53%）——与「低位区买入为主」自洽。

**判定：现有机制不需要按证据补强**；样本升到百笔级后可用同脚本重跑复核（诚实展示）。

## 4. 优化项设计（做 / 不做 / 怎么做 + 证据依赖 + B24 边界 + 看板一致性）

### O1【不做】任何情绪代理入评分、权重、评级判定

- 理由：①检验无一同时满足「两侧 n≥20 + ≥15pp + 跨档方向稳定」；②消息面权重属
  RED_LINES §6 已登记裁定（021BC：0.15→0.08+非对称映射），动它需新证据+用户批准，
  本轮证据恰恰显示**残差增量≈0（7.7pp）**；③R7/classify_stage 零改动（批次硬约束）。

### O2【暂缓 → 观察项】展示层情绪提示（杠杆/主力/量比三类候选）

- 候选与触发条件（全部按月重跑 `query_sentiment_evidence_021bw.py` 复核）：

| 观察项 | 当前证据 | 升级条件（同时满足才做） |
|---|---|---|
| ① 融资余额 5 日快速上升 → 反向提示 | 总体 14.5pp（差一线）、三档方向一致 | 总体差 ≥15pp 保持且档内格升 A 级 |
| ② 减仓档×主力大幅流入（错杀候选） | 单档 33pp（B 级格）、跨档不稳 | 与 021BU「低位减仓错杀」合并跟踪，格升 A 级且跨月稳定 |
| ③ 量比缩量/放量分化 | 总体 +19pp 但跨档跨带方向翻转 | 方向跨档一致化后再议 |
| ④ 新闻词典正面偏置 | 正面:负面=318:36 | 仅影响解读，不影响门槛 |

- **怎么做（若未来达标）**——完全复用 021BU O1 展示模式：`backtest_engine` 新增
  只读聚合纯函数（如 `capital_evidence_note_for(market, rating)`，门槛常量与函数同处
  定义）→ `report-latest` / `watchlist-scores` 响应增只读字段 → 前端小字渲染 →
  审计脚本扩规则（同源同值 + 诚实门 C 级 acc=None）。落点全在读取面/展示层。
- 红线：B24（零触碰本体）；R7（不回灌评分）；样本门槛在**数据层强制**而非前端约定。

### O3【做·本轮即交付】透明说明（合法交付，零代码）

1. 本方案全文即「情绪因子现状」的诚实呈现（对「根据情绪交易」的正面回答）；
