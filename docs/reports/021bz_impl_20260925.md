## 1. 后端：展示层纯函数（modules/market_screener.py）

新增「021BZ 共振展示层」独立段（与库定义同模块，检测逻辑零触碰）：

| 符号 | 语义 |
|---|---|
| `RESONANCE_GRADE` | `{5:'强', 4:'中', 3:'弱'}`——星级重标映射表 |
| `GRADE_NOTE_KEY` | 强弱分级诚实声明模板（{kline_upto}/{window} 占位），全文案禁裸 '<' |
| `strength_grade_for(stars)` | 5/4/3→强/中/弱；None/bool/非整星级/非数字→**None 不硬造** |
| `direction_label_for(kind)` | bull→多 / bear→空；未知→None |
| `latest_trigger_date_of(signals_str)` | `@(\d{4}-\d{2}-\d{2})` 取 max；空/无日期→None——**单一实现**，`trader_advisor._res_date_desc` 改为复用（行为等价，021BR 用例即回归网） |
| `resonance_grade_note(kline_upto, window)` | 声明填充；kline_upto 缺失以「—」占位 |
| `resonance_view(res, kline_upto)` | 原条目浅拷贝 + additive `{grade, direction, trigger_date, timeliness}`；时效=trigger==kline_upto→「今日」，早于→「窗口内历史，非今日」（021BR 语义：历史触发不读起来像新信号）；任一缺失→None |

`run_signal_chunk`：命中结果附 `kline_upto = klines[-1]['date']`（K线在手零新增请求，additive；既有六键全保留，测试锁定）。

**契约锁**：`detect_resonances` / `detect_sell_resonances` 输出键集恰为 `{key,label,stars,kind,note,signals}`、`compute_watchlist_signal_result` / `compute_watchlist_sell_result` 输出键集不变——全部入契约锁测试。alert_engine / action_list 的键白名单拷贝面自动不受影响。

## 2. 端点组装层（blueprints/market.py）

三端点对每条共振条目附 `resonance_view`（响应组装层 additive，检测器零变化）：

- `POST /api/market/scan-signals`：`item['resonances']` → 视图（kline_upto 取自 chunk 结果，时效徽标可用）；
- `GET /api/market/scan/watchlist-signals`：同上（离线链自带 kline_upto）；
- `GET /api/market/scan/watchlist-sell-signals`：`item['sell_resonances']` → 视图（kind=bear→方向「空」）。

在线扫描仍**只产买点**（多侧）；卖侧仅在平行库巡检端点与报告快照出现（021BQ 边界原样）。
