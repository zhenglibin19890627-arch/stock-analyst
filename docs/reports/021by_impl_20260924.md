## 1. 实施清单（C1-C7 全做）

### C1【证据驱动核心】位置分位接入选股流 ✅

**后端**（`modules/market_screener.py`）：
- 新增纯函数 `position_pctile_of_klines(kline_rows, lookback=60, min_bars=40)`
  → `{'pos_pctile': float|None, 'pos_band': 'low'|'mid'|'high'|None}`。
  口径与 `backtest_engine._calc_pos_and_dd20` / `trader_advisor._volume_structure`
  完全同源：近 60 根**收盘**、≥40 根才算、round 3、分带 low<0.4 / mid 0.4~0.7 / high≥0.7。
- `run_signal_chunk` 对每只**命中股**用已拉取的同一份日 K 现算，results 项新增
  `pos_pctile` / `pos_band`——**零新增网络请求**；K 线不足 40 根为 None（不硬造）。

**前端**（`static/js/market.js` + `templates/index.html`）：
- 信号结果表（共振组 + 单一信号组）新增「位置」列：`低位 12%` / `中位 55%` / `高位 85%` / `—`；
  低位绿 / 高位红 / 中位灰（仅视觉分组）。
- 「位置」筛选下拉：全部 / 低位（40%以下）/ 中低位（70%以下）——纯前端过滤，与「只看共振」可叠加。
- 「低位优先」开关（默认关闭）：开启时各组内按 `pos_pctile` 升序、None 殿后；关闭维持现状。

**不做**（与方案一致）：不在第①段/`apply_filters`/快照层做（否决全市场逐票拉 K 线）；
不入库；不进 `SIGNAL_LIBRARY`/`RESONANCE_LIBRARY` 判定；不做打分/仓位映射。
测试 `test_hit_judgment_untouched_by_position` 锁定 matches 与 `detect_signals` 直接输出一致
（位置只做展示/筛选/排序标注，命中语义零改动）。

### C7【审计修复+交互补齐】F1 筛选键对称化 + 粗筛表排序 ✅

- **F1 修复**：新增 `_msFiltersPayload()`——服务端载荷改传 `boards: [v]` / `industries: [v]`
  复数数组键（非空时）；`_msFilters()` 单数键保留给本地过滤与预设存取。服务端零改动。
- **500 截断静默丢弃点核查**（captain 指定确认项）：读 `run_coarse_scan` 代码路径——
  `pre_filters`（除量比外全部条件，**含 boards/industries**）在 `apply_filters(snap['rows'], ...)`
  对全量宇宙（~5553 只）先行过滤，`rows[:500]` 截断发生在其后。**修复后服务端行业筛选
  先于截断生效，「小行业候选被静默丢弃」路径不可达**（修复前该路径可达：单数键服务端
  不识别 → 行业/板块过滤缺位于截断前）。
- **粗筛表三态排序**：现价/涨跌%/换手%/量比/市值 五列表头可点击（↓降序→↑升序→↕默认市值序，
  与 021T 行业资金流表同型交互）；None 值殿后；说明行动态显示当前排序。

### C4【便捷】筛选预设方案保存（localStorage）✅

- 「💾 存为方案」/「方案」下拉 /「🗑 删除」三件套；保存内容 = `_msFilters()` 全部 12 键
  + 信号勾选集 + 触发窗口；localStorage 键 `ms_filter_presets_v1`
  （结构 `{name: {filters, signals, window, saved_at}}`），上限 10 个（超限提示先删），
  同名覆盖需确认；`ms_filter_presets_last` 仅记忆上次使用的方案名（不自动改值）。
- 应用预设：恢复全部筛选值 + 信号勾选 + 窗口；行业下拉在快照已拉取时同步重建并恢复选中。
- **不复用 `strategy_params` 表**（F5 裁定：语义是评分优化审计日志，零新表约束下
  localStorage 是唯一干净落点）。

### C5【便捷】扫描结果导出 CSV ✅

- 粗筛表「⬇ 导出CSV」：导出**当前过滤后全集**（含当前排序，非仅展示的前 100 行），
  列与页面一致。
- 信号区「⬇ 导出CSV」：导出位置筛选后全集（不受「只看共振」视图开关影响），
  列含：代码/名称/命中信号/买点共振(星)/位置/位置分位%/现价/涨跌%/量比/换手%/市值/行业/
  行业资金背景/新命中。
- Blob 生成，UTF-8 带 `\ufeff` BOM（防 Excel 中文乱码），文件名带时间戳。

### C6【便捷】加自选分组直达 ✅

- 「加入自选」条新增分组下拉（数据源 `GET /api/groups?type=watchlist`，含各组自选数，
  懒加载一次，本地库零外部请求）；`msAddSelected` 的 `POST /api/stocks` 请求体附
  `group_id`（端点既有支持，`blueprints/watchlist.py` L323/L351——后端零改动）；
  默认「未分组」。≤20 批量上限与前端拦截原样保留（R16）。

### C2【能力】行业资金流 × 个股候选软联动 ✅

- **后端**（`blueprints/market.py`）：`api_market_scan_signals` 响应为每只命中股附
  `industry_flow_bg`（读库 `industry_fund_flow` 最新交易日，经 `get_industry_flow_bg_map`
  + `match_board_name` 匹配 entries 透传的行业名——与看板行业背景同型同源，不新造匹配器）；
  批统计 `industry_match_hit` / `industry_match_total` 供观察匹配率。
  模块级缓存 `_scan_industry_bg_map()`：key=`交易日|库路径`，同一次扫描 12 批共享一次读库，
  跨库（测试隔离）不串；读库失败降级为无行业列，不阻塞扫描。**零网络**。
- **前端**：entries 透传 `industry`；信号表行业列附 chip
  「行业净流入 +2.3亿 · 连流3日」（匹配成功才显示；streak 为 0 时省略方向段）；
  匹配不上的候选如实不显示（不硬造）。
- 不动行业资金流采集与刷新冷却；不做行业资金流强过滤。

### C3【轻量】重扫「新命中」标记（会话内内存对比）✅

- 本轮正常完成时把命中 symbol 集存入页面变量 `_msPrevHits`（中途停止不改基线）；
  同会话再次扫描后新出现的命中在名称旁标 🆕，结果区顶部注明
  「与上一轮扫描对比：N 只；仅内存对比，刷新页面即清除」。纯前端内存，零存储零网络。
