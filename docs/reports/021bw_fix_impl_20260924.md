## 1. F1（P1）修复：`_tier_for_score` 连续化判定

### 1.1 根因（t3 定位 → 本轮确认）

`modules/rating_hysteresis.py::_tier_for_score` 按闭区间 `[min, max]` 归类，而档位表为
整数边界（A股 强烈建议卖出 0–29 / 建议减仓 30–49 / 持有观望 50–64 / 推荐买入 65–79 /
强烈推荐买入 80–100）——**49–50 / 64–65 / 79–80 / 29–30 存在表缝**，小数分数
（49.7 等）返回 None → `score_tier_mismatch_note` 返回 `''` → 三层标注面全部静默缺失。
引擎本体 `_map_rating` 为连续判定（`score >= min`，按 min 降序取首档），两处口径不一致；
R1 审计 R04 期望档与引擎一致（49.7→建议减仓），故 P1 判定成立。
**影响面**：迟滞最常发生的档位边界区的小数分数＋迟滞保持态报告。

### 1.2 修复内容（展示层，评级判定本体零改动）

1. **判定连续化**：`_tier_for_score` 改为与 `_map_rating` 同款——按 min 降序取首个
   `score >= min` 的档位（容错跳过畸形条目；低于最低档下边界的异常分数返回 None）。
   已验证 `_apply_hysteresis` 不消费此函数（其用 raw/prev 档位 min 做连续比较），
   修复**不改变任何评级行为**——`tests/test_rating_hysteresis.py` 全部既有迟滞用例原样通过。
2. **区间展示稳定化**（防 stored×live 注记文本漂移——首轮实现曾因改动档表内分数的
   区间展示引入 10 条 N08 P1，即时收敛）：
   - 档表内分数：区间展示维持 `min–max` **逐字不变**（与 021BS 存量落库注记一致，
     存量/增量同文本）；
   - 表缝分数（score 超出档表 max）：展示连续换挡边界（上一档 min，如 49.7 →
     「30–50 分」）——此类分数修复前不产注记、无既有文本，展示不自相矛盾。
3. **测试**（`tests/test_rating_hysteresis.py` 新增/修订 6 例）：
   - `test_gap_scores_are_annotated`：49.7/49.99/64.9/79.9/29.5 五组表缝分数全部产出
     含两档位名的标注（禁裸 '<'）；
   - `test_gap_score_tier_for_score_continuous`：`_tier_for_score` 与 `_map_rating` 在
     16 个边界/表缝值上全程一致；-5 返回 None；
   - `test_gap_score_interval_display_uses_switch_boundary`（49.7 → 30–50）＋
     `test_in_table_score_interval_display_stable`（52.0 → 50–64 逐字不变，防漂移回归）；
   - `test_hk_gap_score_annotated`（港股 69–70 表缝）＋
     `test_above_top_tier_annotated_as_top`（150 归最高档，与 `_map_rating` 同款）；
   - 原表缝前行为用例修订：150.0 由「返回 ''」改为「最高档失配标注」（与引擎口径一致，
     -5.0 维持 None）。
4. **审计断言化**（`scripts/audit_consistency_021bs.py` selftest 用例20）：直接锁定
   `score_tier_mismatch_note(49.7/64.9/29.5, …)` 非空且档位名正确、禁裸 '<'——表缝
   回归必被 selftest 捕获。实跑 selftest **6/6 通过**。
