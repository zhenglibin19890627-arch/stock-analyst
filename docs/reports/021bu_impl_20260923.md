## 3. 诚实原则落地（批次铁律）

- **数据层断流**（实现锚点 `backtest_engine.format_evidence_cell`）：
  - A 级 n≥30：`acc` + `display='历史命中 69%（159/230）'`；
  - B 级 20≤n<30：同上 + `grade='B'`，前端渲染「⚠️样本偏小」；
  - **C 级 n<20：`acc=None`、`display='样本不足（n=2）'`**——百分数在数据层即不存在，
    任何消费面（响应/前端/未来消费方）都无法泄漏小样本命中率；
  - 零样本档位（看板缺档）：`empty_rating_evidence` →「样本不足（n=0）」，不返回 null 空洞。
- **边界测试锁定**：n=19（C，无 %）vs n=20（B，可展示）、n=29（B）vs n=30（A），
  审计 r1 selftest 与 pytest 双覆盖（captain 指定的 n=19/20 边界必测项）。
- **审计兜底**：r1 R17 对响应证据对象逐格断言（grade=C 却有 acc / display 带百分数 / acc
  非空缺 n/m → P1）；实测 56 股全部通过。
- **样本量强制伴随**：所有百分数 display 均内嵌「（c/n）」；`_evidence_cell_issues` 对
  「display 含 % 但缺 n/m」判 P1。

## 4. 看板一致性设计（同源同值 + 审计扩展）

结构上消除 stored-vs-live 漂移（O6）。pytest 断言「看板响应值 == 共享函数直调值 ==
报告页响应值」逐字段一致。

## 7. 港股回测样本止于 09-07 的链路核实（captain 移交项，只读核实）

- **现象**：`backtest_results` 港股行止于 2026-09-07；A 股持续增长（09-23 仍有 11 行）。
- **定因**：回测样本由**评级变更驱动**——`advisor.generate_advice` 仅在 `is_changed` 时
  调用 `BacktestEngine().auto_trigger_backtest`（M8-BACKTEST-003，021AG 迟滞进一步
  降低了换档频率）。港股评级写入本身正常（ratings_history 港股行持续至 2026-09-23），
  但 10 只港股自 09-07（唯一一次变更：stock 6 持有观望→建议减仓，恰为最后一条港股
  回测行）后评级全部稳定，**零换档 → 零新增回测样本**。
- **结论**：**链路完好，非故障**；样本将在下一次港股评级换档时自然恢复，或经
  `POST /api/backtest/batch`（手动批量）补算。属数据积累节奏问题，不影响本批次
  港股展示暂缓裁定（O8），无需修复动作。
