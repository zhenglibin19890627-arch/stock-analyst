## 一、方法与口径

### 1.1 未来收益对齐规则（与 backtest_engine._get_tn_price 约定一致）

- 基准价 = `raw_kline` 中 `trade_date <= analysis_date` 的最近一行收盘价（兼容 66 行周末/补跑评分：07-18/07-25/07-26）；
- T+n 收益 = 基准行之后严格第 n 行的收盘价相对基准价涨跌幅（%）；
- 周期：T+1 与 T+5。**T+20 已删除**——分析期最后评分日 08-07 距 K 线末端不足 20 行，实测可用样本为 0，无法计算（评审 P-1 裁定）。

### 1.2 因子与统计量

- 因子（维度级）：基本面 / 技术面 / 消息面 / 资金面 / 综合分（total_score）；
- A股：逐日横截面 Spearman Rank IC（每日横截面独立计算，再对日序列取均值）；
- 港股（横截面过小，每日 1~6 行）：池化秩相关（含按日期秩中心化后的池化秩相关） + 前/后 1/3 分位分组收益差为主指标，逐日 IC 仅作参考；
- ICIR = mean(IC)/std(IC)，**分母（日截面数 n 与 std）一并披露**；
- Spearman 零依赖实现：对平均秩（`rank(method="average")`）做 Pearson 相关，即 Spearman rho 的定义。⚠️ 实现说明：评审 P-5 载明"pandas 3.0.2 原生 `corr(method="spearman")` 可用"，实测 **pandas 3.0.2 该方法内部 import scipy（未安装，ModuleNotFoundError）**；为守住"零新依赖、禁 scipy"红线，本报告以秩+Pearson 手工实现（数学定义等价，纯 pandas/numpy）。此为机制层适配、非统计方法变更，已记入自测报告并提请 PM 知悉评审 P-5 描述勘误。

### 1.4 样本口径与评审基线对账

- 本报告按评审 §2.2 与开发提示词裁定口径：基准价 = `trade_date <= analysis_date` 最近收盘（兼容 66 行周末/补跑评分行）。
- 评审报告/PM 核验载明的 353（T+1）/ 241（T+5）为**仅统计严格相等行**（analysis_date 与 K 线日严格一致的 382 行中剔除末端不足行）的口径：353 = 382 严格行 − 08-07 末行 29；241 = 382 严格行 − 07-31 之后 141（=28+26+29+29+29… 后验）。两口径差异即 66 行周末/补跑行是否纳入。本报告采用 ≤ 口径（全量 448 行尽量纳入），并在各表披露实际样本量，供对照。

### 1.3 资金面填充行敏感性（评审 P-1 硬性要求）

资金面存在"缺失填充"污染（T2 缺陷同源）：评分时 `main_net_inflow IS NULL` 被填充为 0.0 落入 85 分档。标记规则：`raw_capital_flow.main_net_inflow IS NULL` （含评分日无资金面记录的行）为填充行，对资金面维度并列披露"全样本 IC"与"剔除填充行 IC"。

- 填充行计数：A股 T+1 样本 144 行 / 总 344 行（占比 41.9%）；T+5 样本 105 行 / 总 255 行（占比 41.2%）。

### 6.2 港股观察（池化秩相关，横截面过小、可信度更低）

- 港股各维度池化秩相关绝对值均 < 0.26，且 T+1/T+5 符号不稳定；分组收益差多为负（高分组的未来收益不高于低分组），仅消息面 T+1、资金面 T+5 分组差为正。
- 港股样本仅 52~75 行、每日 1~6 行，任何方向性判断的可信度低于 A 股，建议本轮不基于港股 IC 调整权重。

### 6.3 资金面填充行敏感性（P-1 硬性要求的并列披露）

| 口径 | T+1 IC均值 (n) | T+1 ICIR | T+5 IC均值 (n) | T+5 ICIR |
|---|---:|---:|---:|---:|
| 资金面-全样本 | +0.0249 (18) | 0.0875 | -0.0720 (14) | -0.1987 |
| 资金面-剔除填充行 | +0.1150 (14) | 0.4748 | -0.0844 (11) | -0.2416 |

- 观察：剔除填充行后 T+1 资金面 IC 由全样本的 0.0249 升至 0.1150（ICIR 0.0875→0.4748），说明填充行的"85 分虚高"显著稀释了资金面维度与未来收益的正向关系；T+5 两口径均为弱负（-0.0720 vs -0.0844），方向未反转。
- 该敏感性结果同时支撑 T2 修复的必要性（缺失填充 85 分不仅造成"数据越缺分越高"的偏多偏差，还污染了资金面维度的统计有效性）。

### 6.4 权重建议（仅供监理 019U 裁定参考，不自动生效）

1. **资金面（现 A 股 39.85%）**：T+1 剔除填充后为正、T+5 弱负——整体证据偏弱，不建议在缺位修复落地前依据本报告提升其权重；若监理拟下调，建议优先将让渡权重给予基本面。
2. **基本面（现 20.05%）**：T+5 为唯一稳健正 IC（ICIR≈0.51），建议监理评估适度提升。
3. **消息面（现 15.04%）**：T+5 显著负 IC，但样本过小、且消息面数据采集口径脆弱，建议维持现状并观察。
4. **技术面（现 25.07%）**：两周期均非正，建议维持现状观察。
5. 全部建议均受 R-1 样本量约束，监理若裁定调整，建议在 019U 以模拟回测验证后再生效。

## 七、样本量与置信边界声明（R-1 合规）

1. 样本跨度为 2026-07-16 ~ 2026-08-07，仅 17 个交易日、29 只股票；A股每日横截面 2~23 行，港股 1~6 行——均属极小样本。
2. 每日 IC 序列与 std 已逐表披露；ICIR 分母（截面数 n）显著小于 30，按惯例不构成统计显著结论的依据。
3. 本报告所有数字仅为方向性参考；任何"因子有效/无效"的强结论均不被支持。
4. T+5 的有效截面数少于 T+1（评分日越早越有足够后续 K 线），对比时注意样本差异。
