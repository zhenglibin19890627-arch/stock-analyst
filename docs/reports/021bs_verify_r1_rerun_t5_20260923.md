## 5. 复现与口径说明

```bash
python scripts/audit_consistency_021bs.py             # 全量重跑（只读）
python scripts/audit_consistency_021bs.py --selftest  # 合成用例自检（规则可信性）
python scripts/audit_consistency_021bs.py --stock 21  # 单股复跑
```

- 报告面 = daily_reports 存量行（report_type=daily, status=ok, 每股最新一期）；
- 现算面 = trend_analyzer / trader_advisor 纯函数经 test_client 只读端点现算；
- 时点差分级依据：kline_upto（raw_kline 最新交易日）== report_date 视为同数据日
  （不一致升级 P1），否则视为时点差（P2，重生成报告自愈）；
- 持仓数据变更（如用户当日增删持仓）会造成存量报告与现算的成本基数差异，
  审计按「数据变更型时点差」分级为 P2 并在现象中注明，避免误报为代码矛盾；
- 本脚本零写库（sqlite mode=ro 硬保证）、零网络（只调本地 test_client 只读端点）、
  不触碰 B24（advisor.generate_advice）与评分引擎 R7/classify_stage（021BQ 锁）。
