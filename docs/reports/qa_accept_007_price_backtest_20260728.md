## 六、观察项与改进建议

### 观察项 1（中优先级）：报告命中率统计存在"稀释"效应

**现象**：`compute_price_backtest_report()` 中的 `_hit_rate()` 函数统计所有行（含不适用行），导致：
- 买入区间命中率被 has_position 行稀释（has_position 行的 buy_range 始终为 0）
- 止盈价命中率被 no_position 行稀释（no_position 行的 take_profit 始终为 0）
- 报告显示 T+20 买入区间命中率 = 65.88%，但实际 no_position 子集为 **86.68%**
- 报告显示 T+20 止盈价命中率 = 10.77%，但实际 has_position 子集为 **44.89%**

**影响**：
- 不影响回测引擎本身的正确性（逐条命中判定逻辑正确）
- 影响参数微调诊断框架的准确性（设计文档 §6.1 的阈值基于"总回测点数"，但 has_position 行不应计入买入区间分母）
- 前端展示的命中率数值偏低，可能误导用户

**建议**：后续优化 `_hit_rate()` 按 has_position 分拆统计，或仅统计适用行。**不阻塞本次验收**。

### 观察项 2（低优先级）：报告字段命名与任务书预期略有差异

| 任务书预期字段 | 实际字段 | 状态 |
|---|---|---|
| total | total_points | 功能等价 |
| hit_rate | hit_rates | 功能等价 |
| by_rating | rating_stats | 功能等价 |
| overall_score | composite_score | 功能等价 |
| date_range | （缺失） | 无影响 |

**影响**：不影响功能，仅字段命名风格不同。API 返回的 JSON 完整可用。
