## 2. O5①：换手率字段断供——根因、修复与回补

### 2.1 根因诊断（对 t1 假设的修正）

| 项 | 实证 |
|---|---|
| t1 假设 | 「疑似 K 线采集源切换时字段丢失（腾讯/mootdx 两源都查）」 |
| 实测结论 | **两源从来就不提供换手率**：腾讯 `fqkline/get` 返回 [日期,开,收,高,低,量]，mootdx（通达信 pytdx bars）返回 OHLC+vol+amount——均无换手率；而 `fetch_kline` 入库 SQL 自工作区基线提交起就**硬编码 `0`（注释「换手率（同上）」）** |
| 数据实锤 | 全库 `raw_kline` 25,541 行 turnover **无一非零**（含窗口前历史行）；git `-S` 追溯该硬编码至基线提交，无中途变更 |
| 判定 | 「2026-07 起恒 0」实为 t1 回测窗口与「全库恒 0」的观察重合——**字段从未成功采集过**，属采集写回缺陷而非源切换丢失 |

### 2.2 采集写回修复（`modules/collector/kline.py`，＋122 行）

- **换手率旁路**（东财日K `push2his/api/qt/stock/kline/get`，`fields2` 末位 `f61`=换手率%，实测
  A股 `1.600276` 与港股 `116.00700` 均返回）：
  - 纯函数三件：`_em_secid`（沪 1./深 0./港 116.，不支持返回 None）、
    `_parse_em_kline_turnover`（按固定列序解析，**0/负值=缺失不入表**）、
    `_merge_turnover`（按 日期 列对齐合入 `换手率`，未命中行=0，不改入参 df）；
  - `fetch_kline_turnover_em(symbol, market, lookback_days=None)`：旁路请求——复用
    `_http_get_em`（019X UA 池/019Z 全局最小间隔），**`max_retries=1` 单轮封顶**，
    不走 30~60s 轮间退避（换手率是展示/检验维度，旁路失败不得拖慢主采集链）；
    失败返回 `{}` 优雅降级，价格五档仍全部来自腾讯/mootdx 主链（**不引入新价格源**）；
- **入库语义（只升不降）**：写库前读取该股既有非零 turnover，旁路值优先、旁路缺失沿用库内
  真值、两者皆无才写 0（=缺失语义，下游 `bucket_turnover` 同口径）——旁路失败日历史真值
  不被 0 覆盖；`_refresh_kline_today_bar` 既有保留逻辑不变；
- **影响面核查**：`raw_kline.turnover` 无任何评分消费方（grep 全仓：仅 t1 查询脚本与
  market_screener 独立表），修复**评分中性**（R7 安全）；facade 全量再导出面零变化
  （新增符号不入 facade，OPT-3 192 符号快照不受影响）；R15 签名零改动。

### 2.3 历史断供段回补（新 `scripts/backfill_kline_turnover_021bw.py`）

- 设计：与采集侧**同源同函数**（`fetch_kline_turnover_em`，单一真相）；`UPDATE ... WHERE
  turnover IS NULL OR turnover <= 0` **只填缺失绝不覆盖非零真值**；写库前
  `db_manager.backup_database`（R11 精神，失败即中止）；`--dry-run` 盘点/`--pause` 逐股
  节流防 WAF 频控/失败股多轮冷却重试（幂等，可随时续跑）；逐股诚实统计失败原因。
- 执行实录（2026-09-24）：
  | 轮次 | 参数 | 结果 |
  |---|---|---|
  | 首轮 | 默认 | 备份 `db_backup_20260924_113312`；**回补 15,159 行（19/56 只全量）**；~16 只后东财 WAF 进入窗口式丢弃（RemoteDisconnected，019W 已知行为） |
  | 续跑 | `--pause 4 --retry-passes 3`（轮间冷却 150s） | 备份 `db_backup_20260924_113656`；仅 **600487 亨通光电 +268 行**；36 只在三轮中持续被 WAF 丢弃（本次为长窗封禁，远超 019W 记录的 2~4 分钟） |
  | 延迟终跑 | 冷却 25 分钟后 `--pause 6 --retry-passes 1`（12:18） | 备份 `db_backup_20260924_121830`；**0/36 成功**（封禁贯穿整个任务窗口，约 45 分钟+）——脚本按设计如实返回「全部失败」退出码 1，不再继续敲接口（防延长封禁） |
- **当前状态（定稿）**：累计 **15,427/25,541 行（60.4%）**，20/56 只全量；值域核验
  0.08~22.52%、日均 1.52%、无 >40% 异常值（601888 日换手 0.39~0.76% 与大盘股量级吻合）
  ——数据可信；未补齐的 36 只经 45 分钟内三轮＋延迟终跑共 5 次尝试确认被东财 WAF 长窗封禁；
- **边界（诚实记录）**：余 36 只（含全部港股与部分中小盘）受东财 WAF 频控未能在本任务窗口内
  补齐。**采集写回已修复**——每只股票下一次日常 `fetch_kline` 全量刷新即自动带旁路值落库，
  届时缺失行亦被「只升不降」语义自然补齐；或随后续空闲时段重跑 `python
  scripts/backfill_kline_turnover_021bw.py`（幂等、先备份）批量补齐。属**可自愈的数据时点差**，
  非代码缺口。
