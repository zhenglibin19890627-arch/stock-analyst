> **性质**：设计提案（未实施）｜ **编制日期**：2026-10-10 ｜ **状态**：待用户裁定关键决策点
> **缘起**：用户对今日行动清单共振星级的质疑（星级分布、获取难度），经多轮讨论收敛为本方案。
> **红线合规预告**：不触碰 B24（generate_advice）/R7（scoring_engine 核心）/R8（数据契约）；
> `market_screener.detect_*` 输出契约受 021BZ 锁定测试保护，本方案涉及**增量字段**（阶段槽），

## 1. 问题陈述（实证）

### 1.1 星级分布畸形（2026-10-10 行动清单实测）

当日买侧信号 16 个：**13 个 5★**、4★ 与 3★ **零出现**、3 个无共振；卖侧 8 个：7×5★ + 1×3★。
5★ 占有共振信号的 100%，用户视角的"5 星"已失去区分度（通胀）。

### 1.2 结构性根因：星级与趋势环境强相关

取最高档优先序（周线共振 > 底部反转 > 二次金叉 > 双金叉）导致：
**双金叉（4★/3★）只在周线非多头时浮出** → 低星 ≈ 弱环境里的信号。
强环境里任何日线金叉都收编为 5★（信号稀释），弱环境里同日双金叉被环境二次惩罚。

### 1.3 获取难度与星级倒挂

| 组合 | 星级 | 条件本质 | 粗估触发难度 |
|---|---|---|---|
| 周线共振波段 | ⭐5 | **状态**（周线 DIF>DEA，持续数月）+ 事件（3 日内日线金叉，单股 15~25%） | **最低**（全市场扫一次可出数百只） |
| 双金叉·同日 | ⭐4 | 事件 ∧ 事件（MACD 金叉 ~1/30 日 与 KDJ 金叉 ~1/15 日**同日**） | 显著高于周线共振 |
| 底部反转 | ⭐5 | 底背离 + KDJ 低位金叉 + 放量阳线（三合取） | 最高 |
| 零轴上二次金叉 | ⭐5 | 15 日内第 2 次 DIF>0 金叉 + KDJ 中位金叉 | 较高 |

→ **4★ 同日双金叉比 5★ 周线共振更稀有**：难度序与星级序倒挂。

### 1.4 其余缺陷

- **5★ 内部同质化**：周线共振（顺趋势波段）/ 底部反转（左侧抄底）/ 零轴上二次（主升中继）语义与风险特征完全不同，共享同一标签无内部序；
- **成分质地不进星**：⭐4 可由「水下金叉 + 普通金叉」弱变体拼成，与「水上 + 低位」强变体同星（021BP 相悖调和文案本质是给此缺陷打的运行期补丁）；
- **周线在途重绘风险**：周 K 若含本周未完成 bar，DIF>DEA 判定随本周价格漂移（周中 5★ 周五可能消失），待实跑确认；
- **无实证校准**：四组共振的分档 T+5/T+20 命中率从未统计，星级为设计理论值而非数据校准值。

### 1.5 语义混淆的核心（讨论结论）

反转类信号**只出现在刚大跌过的股票上**（成立条件含价格 60 日新低），其 5★ 表达的是
"形态确认强度"（时机好），用户读成的是"上涨概率"（方向好）——两者在逆势信号上恰好背离。
**结论：星级只能表达时机质量；方向必须由评级/趋势维度独立表达，二者并列展示、不得折叠。**

## 2. 设计目标与原则

1. **三问三答**：一只股票每天被回答三个不同的问题，各用各的槽位，不合并计算：
   - 阶段（状态）：指标现在处于什么阶段？——回答持有逻辑是否延续；
   - 时机（事件）：切换点是否出现？——回答要不要动手；
   - 方向（评级）：该不该往多的方向做？——回答许可与仓位语义。
2. **状态不冒充信号**：阶段是常态（持续数周），事件是脉冲（稀缺）。二者并列展示，**绝不合并星数**（否则状态星天天满星，事件星被淹没，重蹈 1.2 通胀）。
3. **克制**：健康修正只减不加；无新依赖；纯函数；展示层增量，判定层最小改动。
4. **零代码用户可读**：最终交付仍是一行白话结论（行动清单 reason），槽位是结构化支撑。

## 3. 方案设计

### 3.1 三槽位总览（单行装配示例）

```
拓尔思 300229 ｜ 阶段 ▲多头（MACD红柱扩张·KDJ 62↑） ｜ 时机 3★（KDJ金叉·跨日） ｜ 方向 ✗ 减仓(50.8)
              → 行动语义：仅短线反弹参考，严止损
```

### 3.2 阶段槽（新增，状态判定，纯函数）

| 阶段 | 判定（候选规则，待回测定稿） |
|---|---|
| ▲ 多头 | DIF>DEA **且** 当日 MACD 柱体 ≥ 前日柱体 **且** K>D |
| ▼ 空头 | DIF<DEA **且** 柱体继续收缩(空头) **且** K<D |
| ◌ 纠缠 | 其余（含柱体转向但交叉未发生、KDJ 交叉缠绕） |

- 数据源：`_macd_series` / `_kdj_series`（`market_screener.py` 现成，零新依赖）；
- 展示位：**持仓页、行动清单持有股、报告页趋势罗盘卡片旁**（罗盘管价格趋势，阶段管指标动量，互补）；
- **不进入选股候选排序**（避免常态状态灌满候选列表——见 §2 原则 2）。

### 3.3 时机槽（现有共振星，修订三处）

| # | 修订 | 内容 | 解决 |
|---|---|---|---|
| T1 | 周线用已完结周 | 周线 DIF>DEA 判定剔除在途 bar（`weekly_rows[:-1]`） | 消除盘中重绘 |
| T2 | 周线共振降档（**决策点 D1**） | 选项 A：立即降 4★；选项 B：维持 5★、等 §5 校准结果定 | 难度倒挂 |
| T3 | 叠加不折叠 | 命中多组共振时主组合之外以「叠加：底部反转」注记透出 | 保留最强共振信息 |

成分变体加权（水上>水下、低位>普通）列为 **T4 备选**，待校准数据支持后再做。

### 3.4 健康修正（时机星的角标，只减不加）

```
时机星 = 组合基础星 − 修正项（下限 2★）
  −1  RSI>70 超买追高（数据已算，detect 环境注记现成）
  −1  近 20 日金叉死叉 ≥3 次（震荡骗线环境，新增计数）
  −1  金叉无量能确认（对未含量能条件的组合）
```

阈值（70 / 3 次）为初始值，**以 §5 回测分档表现复核**。

### 3.5 方向槽（现有评级，零改动）

评级 ≥ 持有观望 → ✓（绿）；≤ 建议减仓 → ✗（红）。**不新建方向指标**——v5 评级含基本面/资金面，
方向判断是它的专职；任何纯技术"健康度"另立方向结论都会与它打架（三套判断并存 = 用户无所适从）。

### 3.6 行动语义矩阵（固化 021BP 相悖调和为规则表）

| | 方向 ✓（≥持有观望） | 方向 ✗（≤建议减仓） |
|---|---|---|
| **时机 5★** | 正常买入候选 | 仅短线反弹，严止损 |
| **时机 4★** | 可建底仓 | 观察等确认 |
| **时机 3★/无共振** | 持有等信号 | 回避 |

现行动清单的相悖调和文案（021BP）升级为本矩阵的系统输出（文案仍禁裸 `<`，R 合规）。

## 5. 实证校准（根治步骤，独立批次）

用 `technical_backtest` 管线按**共振组合分档**回测 T+5/T+20 方向命中率：
- 分档维度：组合类型 × 成分变体质地 × 健康修正档 × 方向档（与评级交叉）；
- 产出：每档触发频率 + 命中率 + 盈亏比 → **星级档位由命中率分带映射**（如 T+20 命中率 ≥55% = 5★带）；
- 校准后复核 D1（周线共振档位）与健康修正阈值；
- **分布监控**：`scripts/data_source_health.py` 或审计脚本加每档当日触发频率快照，防通胀回归。

## 7. 风险、回退与验收

- **7.1 回退**：阶段槽/叠加注记为纯增量展示，回退即隐藏；T1 完结周为判定收紧，回退恢复原读取；
- **7.2 不变量**：R9/R10 写库不变量无关（本方案零写库，纯读算显）；选股器仍只产买点、卖点走平行库（021BQ 隔离不破坏）；
- **7.3 风险**：阶段判定规则未经回测可能误标（纠缠/多头边界抖动）→ 首版保守（条件全满足才标 ▲/▼，其余归 ◌）；行动清单文案变长 → 控制槽位注记 ≤20 字；
- **7.4 契约锁**：021BZ 契约锁测试（detect_* 输出键集）需随新增 `phase` 字段修订——属增量修订，逐字保留既有键；
- **7.5 验收**：①pytest fast 全绿（含修订后契约锁）②红线 28/28 ③ruff/mypy 0 错 ④行动清单/持仓页/报告页三处展示逐槽位对照用例 ⑤分布监控上线并出首份快照。
