**裁定：**

2. **Rank IC 按"逐日横截面"计算**：A 股每日 n≈22，17 个截面；港股每日 n≈5，**单日 Spearman 无统计意义**，港股部分改为：①逐日 IC 仅作展示；②以"池化秩相关（按日期去均值后合并）"与"分组收益差（前 1/3 高分 vs 后 1/3 低分，T+1/T+5 平均收益差）"作为主指标。分组收益差对横截面小的场景更稳健，同意评审提示中的建议方向。
3. **ICIR 必须披露分母**：ICIR = mean(IC)/std(IC)，17 个截面、std 天然巨大，报告须同时给出 n、std、每日 IC 序列，并文字声明"结论仅方向性参考，不宣称统计显著"（R-1 硬约束）。
4. **Spearman 用 pandas 原生实现**（`df.corr(method='spearman')`，内部秩+Pearson），已实测 pandas 3.0.2 可用、**scipy 未安装**——不引入 scipy，符合零代码红线。
5. **资金面填充行敏感性分析（新增硬性要求）**：capital_score 存在"缺失填充"污染（见 2.3 与 T2 节：08-06 当日 23 行 A 股 main_net_inflow 全 NULL，全部以填充值评分）。T1 报告必须：①通过 `raw_capital_flow` 关联标记 `main_net_inflow IS NULL` 的评分行；②对 capital_flow 维度分别计算"全样本 IC"与"剔除填充行 IC"，两者并列披露。否则 capital_flow 的 IC 结论将被系统性偏多偏差污染，恰恰违背本批次立项初衷。

## 三、T2 遗留项⑨修复评审（本批次最高风险项）

### 3.1 缺陷确认与影响实证

- 代码缺陷确认：`scoring_engine.py:766-788` `score_main_capital()`，`inflow is None → NEUTRAL_INFLOW=0.0 → inflow >= 0 → 85.0 分`；子项 `main_capital` 为 C 类 keep_default（权重恒 0.55）。`score_north_capital()` L795 缺失→70.0、`score_margin_capital()` L816 缺失→68.0，同族偏暖。
- 现网影响实证（只读）：`raw_capital_flow` 全表 3086 行中 **675 行（21.9%）main_net_inflow 为 NULL**；**2026-08-06 当日 23 行 A 股全部 NULL**（EM 接口挂停日，与 019Q 报告的 000001 现场故障同款）。08-06 的 analysis_results 中 capital_score 出现 **79.0（3 行）**——按归一化权重核算：85×0.636 + 70×0.081 + 68×0.283 ≈ 79.0，完全吻合"缺失→85 分热填充"路径。偏多偏差坐实，且发生过全日性系统事件（08-06），不是理论瑕疵。

### 3.2 方案裁定（评审要点 1）

**裁定：方案 b（A 类归零），并配套"缺失分支返回 50 分仅作展示诚实化"。**

论证（独立判断，支持 PM 倾向）：

1. **方案 a（缺失→50 中性分）缺点**：缺失只改了分值、不改权重。全部缺失时 capital 维度 = 50×0.636 + 70×0.081 + 68×0.283 ≈ 56.7（北向/两融偏暖残存），且 50 分仍以 0.55 权重占据维度均值的 63.6%，把"无信息"当"中性偏多"的变相占权，与 Q03 降级哲学（缺失=无信息→不占权重）矛盾。
2. **方案 b（缺失→权重归零）优点**：main_capital 为单字段子项，改为 A 类归零后语义精确等价于"无主力数据当日资金面主体无信息，权重让渡给其余真实子项"，与既有 A 类机制（如 `adjust_subitem_weight` 的 `'zero'` 分支）零新增概念；当北向/两融亦缺失时维度整体不可用，走既有维度级归一化（`_normalize_dim_weights`）路径。
3. **必须配套**：`score_main_capital` 缺失分支同时改为返回 50.0 + note（不返回 85 的填充分），否则子项明细表会显示 85 分（权重 0 掩盖不了展示层的误导）。这与"缺失场景不得产生偏多得分"验收一致。**此项为 P-2 硬约束**。
4. **零回归由构造保证**：main 有实测值时，A 类权重返回 base_weight（=C 类行为）、评分走实测档位分支，与修复前逐位一致。

**开放项 A 裁定（同批修复）：** north/margin 缺失偏暖分（70/68）**同批修复为缺失→50 中性分**，但**保持 B 类降权不变，不改为 A 类归零**。理由：①同族偏暖缺陷，改动点各 1 行，成本极低；②若将 north/margin 也改 A 类归零，会改变"main 实测 + north/margin 缺失"行的维度归一化权重（0.55+0.10+0.35 组合与 0.55+0.245 不同），扩大回归面；③两子项 base 权重合计 0.45，归零与降权对维度的差异不足以覆盖其回归风险。**P-2 约束：north/margin 只改缺失分支返回值 70→50、68→50，不动 degradation 类型。**

### 4.3 判定矩阵升级口径（评审要点 3，R-4 降级预案）

**裁定：采纳 PM 方案——新增 alpha 判定列，不推翻 is_correct。**

- `is_correct`（绝对收益口径）与 `is_correct_alpha`（超额收益口径）**并存对照**，历史报告不受破坏。
- **alpha 判定复用既有 JUDGEMENT_MATRIX 阈值结构，作用于 alpha 值**：例如 强烈推荐买入 = alpha≥1.0% 正确 / alpha≤-3.0% 错误；持有观望 = -2.0%≤alpha≤2.0% 正确。即"口径变、阈值语义不变"，避免另起一套阈值引发二次口径争议。
- **基准缺失降级**：`bench`/`alpha` 对应列全 NULL、`is_correct_alpha=NULL`（不判定），`is_correct` 照常；港股在采集修复前一律走此降级，**不引入其他代理基准**（避免跨市场口径争议），修复后自动补齐。
- **时间对齐**：基准基准价 = `index_kline` 中 `trade_date <= rating_date` 的最近一行收盘；T+n 与个股同取"第 n 行严格之后"（与 T1 规则、`_get_tn_price` 约定一致，R-3 复用）。
