## 一、独立核验的核心发现

### 发现 1（A-1 决定性）：`stock_financial_abstract` 实测——PM 核心实证成立，但"需转置"表述错误

**独立实测（akshare 1.18.53，600276 恒瑞医药）**：`df = ak.stock_financial_abstract(symbol='600276')` 返回 shape=(80, 106)。

| 项 | 实测结果 |
|---|---|
| 结构 | 行=80 个指标；列=`['选项','指标']` + 104 个报告期列；**无需转置**——本就是"行=指标、列=报告期" |
| 关键 | `选项` 列 7 组（常用指标/每股指标/盈利能力/成长能力/收益质量/财务风险/营运能力）；**同一指标名出现多次**（如'毛利率'×2、'净资产收益率(ROE)'×2、'归母净利润'×2），按名匹配必须去重 |
| 报告期列 | 最新在前：`20260331 → 19971231`（104 期全历史）；格式 `20260331` 需转 `2026-03-31` |
| 毛利率 | 20260331=**86.598607**（PM 所述 86.60 ✅）；20251231=86.206966 |
| 销售净利率 | 28.020101（与现接口/DB 值 28.0201 **完全一致** ✅ 同源） |
| 营业总收入增长率 | 20260331=12.975362；20251231=13.024342（与 DB 13.0243 一致 ✅） |
| 净资产收益率(ROE) | 20260331=**4.15**（常用指标组）；'摊薄净资产收益率'=3.58699；'净资产收益率_平均'=3.654601 |
| 资产负债率/流动/速动 | 10.024391 / 9.233057 / 8.721048 ✅ 全部有值 |
| ocf_to_profit | 对应行'经营活动净现金/归属母公司的净利润'在 20260331 为 **NaN**（现接口该期有值 0.3448，见发现 2） |

**结论**：PM 核心实证（毛利率有值、全历史、同新浪源）**成立**；但 PM 所述"行=指标、列=报告期，需转置适配"**不准确**——结构无需转置，适配要点是"按 `指标` 列取行（去重）+ 按报告期列遍历（最新在前）"。

### 发现 2（决定性）：DB 实证——"29 只毛利率全空"实为"21 只 A 股"，且双接口存在字段级值差异

- **21 只 A 股（有 raw_fundamental 行）gross_margin 全部 NULL**（gm_cnt=0）；ROE/net_margin/debt_ratio/revenue_growth 有值（4~9 期）；总自选股 29 只（23 A + 6 HK），其中摩尔线程 688795/沐曦 688802 **无任何基本面行**。
- **港股 6 只的"字段不全"根因不是 EM 源限制**（PM 认知，需修正）：实测最新行（2026-07-22，5 只）**全部字段为 NULL**——这是 `fetch_hk_fundamental` L1047-1058 "无财报记录时创建今日日期占位行"（仅 PE/PB）产生；真实财报行（2025-12-31 等）**字段有值**（ROE/毛利率/净利率/负债率/营收增长齐全）。`data_adapter` L244 `ORDER BY report_date DESC LIMIT 1` 读到占位行 → 展示/评分侧全空。**快手（HK1024）无占位行**（最新=2025-12-31 真实年报）→ 与 PM"快手除外"观察吻合，佐证根因。
- **双接口字段级值差异**（恒瑞 600276，stock_id=4，DB 现接口 vs abstract）：
  - ROE 20260331：DB=**3.59**（现接口'净资产收益率(%)'≈摊薄口径）vs abstract 常用指标组=**4.15** vs abstract 平均口径=3.65；
  - 净利润增长率：DB=21.5596（'净利润增长率(%)'）vs abstract 归属母公司=21.782316；
  - ocf：DB=**0.3448**（有值）vs abstract 20260331=**NaN**。
  → **纯方案 A（全替换）会造成 ocf 数据回退与 ROE 口径迁移**，回归红线（"既有字段值不被破坏"）要求 ocf 保留保护。

### 发现 3（决定性）：TTL 认知修正——港股非"14 天 TTL"，为 80 天共用常量

`fetch_hk_fundamental` L947 用 `FUNDAMENTAL_REPORT_TTL_DAYS`（80）判断；DB 中"同日跳过(港股财报14天内)"的"14天"是 **elapsed 天数**（07-22 采集，08-05 时隔 14 天），非 TTL 值。任务书"港股：14 天 TTL（L936-949）"表述错误（不影响"TTL 已有"结论，但需事实修订）。

### 发现 4（决定性）：次新股缺口由 abstract 顺带解决

**实时实测**：摩尔线程 688795 / 沐曦股份 688802 —— `stock_financial_analysis_indicator` 返回 **shape=(0,0) 空**（PM 所述属实）；`stock_financial_abstract` 返回 (80, 11)=**9 个报告期**（20260331→20221231），毛利率=67.35/60.05、营收增长率=155.35/75.37 ✅ **有值**。换源后次新股基本面缺口自动闭合，无需额外方案。

### 发现 5：`_call_with_timeout` 是 THS 函数内闭包，非模块级可复用函数

L1153-1165 的 `_call_with_timeout` 定义于 `_fetch_capital_flow_ths_batch`（L1121-1192）内部。任务书"复用 _call_with_timeout（L1153-1165）"在**不触碰 019I/019N 已验收代码**的前提下不可直接 import——019P 须在基本面区域自建同型 daemon-thread 闭包（复制 019I 模式），公共化提取登记技术债。

## 二、逐决策点裁定

### A-1：毛利率补全方案选型（核心）—— **裁定：方案 A'（abstract 主源替换 + 3 项衔接保护）；否决纯 A 与纯 B**

2. **字段映射表（实测行名）**：
   | DB 列 | abstract 指标行 | 说明 |
   |---|---|---|
   | gross_margin | '毛利率' | 核心修复，86.60 ✅ |
   | net_margin | '销售净利率' | 与现值一致 ✅ |
   | revenue_growth | '营业总收入增长率' | 与现值一致 ✅ |
   | profit_growth | '归属母公司净利润增长率' | 值 21.56→21.78，归母口径更标准，接受 |
   | roe | '净资产收益率(ROE)'（常用指标组） | **值迁移 3.59→4.15**（现接口为摊薄口径），同源不同算法，接受并文档化；QA 断言值域合理（0<v<100）而非精确值 |

4. **B10 链路（L2865-2910）不改**：abstract 全字段写入后 dedup 检查（L2897 non_null>=5）自然跳过；`fetch_fundamental_detail`（L738-779）保留现接口作为回补/降级层。
5. **数据完整性裁定**：abstract 覆盖现写全部 9 字段（实测），**无需混合方案补字段**；混合仅体现在"保护"层（ocf/降级），故定名 A'。
6. **顺带收益**：次新股（688795/688802）缺口自动闭合（发现 4）。
7. **估值（PE/PB 腾讯源）流程不变**：财报重采时 skip_pepb 恒为 False（L580-596 仅在 skip_financial=True 分支内赋值）→ PE/PB 必重取并合并至最新真实行（L697-716）→ REPLACE 清空最新行 PE/PB 后必被重新合并，无丢失风险（核验确认）。

### A-2：趋势分析设计与评分影响（核心）—— **裁定：仅展示不进评分（确认 PM 倾向）；口径双轨制；输出三处 + 前端一处**

**裁定**：
1. **不进 v5 评分**（确认 PM 倾向，独立裁定）：① v5 FUNDAMENTAL_SUBITEMS（scoring_engine L177-183）均为快照指标，趋势进评分需改 data_contract（30 字段红线）+ scoring_engine + 权重配置，范围爆炸；② 019E 评分纯净精神——评分反映当前快照，趋势是派生信息，两者解耦可避免"新财报发布→趋势翻转→评分跳变"的季度性抖动；③ 监理诉求是"要有改善/恶化说法"（可见性），非评分化。→ scoring_engine / config_weights / data_contract **零改动**。
2. **口径双轨制（环比受限 + 同比兜底）**：
   - **环比（相邻报告期直接比较）仅限期间/时点型指标**：毛利率、净利率、资产负债率、流动比率、速动比率（季节性本身是信息，文案可注明"较上期"）；
   - **累计型指标 ROE 禁止环比**（实测 Q1=4.15 vs 年报=14.26，跨类型比较无意义）→ **仅同比**（最新期 vs 去年同期**同类型报告期**，report_date 前推 1 年匹配，无同期数据则跳过该指标）；
   - **同比指标（营收/净利增速）**不做"环比"，表述为"增速加快/放缓"（比较相邻两期增速值）；
   - **变化阈值**：|Δ| < 1pct 视为"平稳"（防噪声，QA 断言依据）。
3. **粒度：单指标 + 汇总双轨**：`fund_trend`（汇总：基本面环比改善/恶化/平稳，多数投票 + 阈值）+ 单指标趋势串（ROE 同比、毛利率环比等 2~3 条），接入点：
   - 改善 → `_describe_dimension` 基本面分支（L212-221）highlights 追加趋势文案（评分理由）；
   - 恶化 → `_detect_risks` 基本面分支（L404-406 附近）risks 追加恶化提示（风险提示）；
   - 前端因子卡：`_factorPriority.fundamental`（index.html L5172）首位插入 `fund_trend` + `_dimFactorLabels`（L5185-5189）+ tooltips（L5211-5218）——保证因子卡必显（监理"就一条不够"的可见性落地）；
   - 日报关键因子：`_pick_top_factors` 基本面优先级（advisor L449-458）插入 `fund_trend`。
4. **数据源**：raw_fundamental 多期行（A' 写 8 期 + 存量回补后天然具备）；计算在 `_build_fundamental_factors`（L1068-1108）内完成（`SELECT ... ORDER BY report_date DESC LIMIT 8`），**B24 红线零触碰**（generate_advice L1198 及其主体不改，调用链 L1217→L881→L1003 均为既有函数内增量）。
5. **混合来源比较接受**：存量旧期（analysis_indicator）+ 新期（abstract）混合比较，同新浪域值可比，文档化说明。

**理由**：口径双轨制直接解决任务书"Q1 vs 年报不可比"的悬案（实测 ROE 4.15/14.26 悬殊佐证）；输出位置三处+前端一处保证"改善/恶化"在评级理由、风险提示、因子卡、日报四个用户可见面出现，满足监理核心诉求且不触碰评分稳定性红线。

### A-3：来源标注实现 —— **裁定：加列（data_source）+ message 前缀 + 前端动态表头，三通道**

**裁定**：

### A-6：存量数据回补 —— **裁定：自动回补（TTL 门控附加完整性检查），否决手动与不处理**

**裁定**：
1. **机制**：`fetch_a_fundamental` TTL 门控（L560-605）附加完整性检查——`skip_financial` 判定为 True 前，查最新一期行 `gross_margin IS NULL` → **不跳过财报采集**（走 abstract 全字段重采）。零代码自动（每日报告/采集流程自然触发），无需用户任何操作。
2. **收敛性**：abstract 一次重采即写入 8 期含毛利率 → 完整性检查通过 → 后续恢复"同日跳过"。**前提**：HK 占位行修复（A-4）——否则港股每日触发且永不收敛。
3. **与 011 TTL 兼容性（红线 4）**：TTL 门控语义不变（完整数据仍 80 天跳过）；"不重复获取"红线语义为"已有完整数据不重复获取"，完整性缺失时获取缺项不构成重复（B10 先例精神）。
4. **message 区分**：回补场景 data_status 消息标注 `'财报补全(毛利率缺失触发)'`，与"同日跳过"区分，避免用户困惑（R-4）。
5. **否决手动**：force_full 需人工操作，违反零代码；**否决不处理（自然过期 80 天）**：监理"完善数据"隐含存量补全诉求（PM 备注 4），80 天等待不可接受。
6. **回补范围**：全部 A 股（21 只有行股票 + 2 只次新股无行自然采集）；港股经 A-4 修复后同机制收敛。

**理由**：启动即用（零代码）、自动收敛（补全后停止）、与 TTL/回归红线兼容；实测确认 abstract 单次调用 ~1s 无性能风险。
