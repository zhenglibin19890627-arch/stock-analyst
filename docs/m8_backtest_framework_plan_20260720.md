## 一、需求基线对标

### 1.1 需求原文(§2.8 全文引用)

> **§2.8.1 回测机制**
> - 固定周期回测:评级发布后1天、1周、1月的股价表现
> - 动态周期回测:评级发布至下一次评级变更期间的表现
> - 触发条件:每次评级变更自动触发回测
> - A股和港股分别独立回测(因市场特性不同)
>
> **§2.8.2 有效性判定**
> - 对比基准:仅对比个股自身历史表现,不与大盘或行业指数比较
> - 判定逻辑由开发方设计(例如:买入评级后股价上涨=正确,卖出评级后股价下跌=正确)
>
> **§2.8.3 回测结果存储**
> - 永久存储,用于后续优化分析
> - A股和港股分别存储,可分别查看回测效果

## 三、回测方法论

### 3.1 有效性判定矩阵(§2.8.2 设计)

> 需求原文:"买入评级后股价上涨=正确,卖出评级后股价下跌=正确"

| 评级档位 | 方向预期 | 判定公式 | 备注 |
|---|---|---|---|
| A(强烈推荐买入) | 上涨 | `return_N > +2%` → 正确;`< -3%` → 错误 | 中间区为"中性" |
| B+(推荐买入) | 上涨 | `return_N > +1%` → 正确;`< -2%` → 错误 | |
| B(谨慎买入/持有) | 微涨/横盘 | `return_N > 0%` → 正确;`< -2%` → 错误 | |
| C(持有观望) | 横盘 | `-3% < return_N < +3%` → 正确 | 双向偏离为错误 |
| D(建议减仓/卖出) | 下跌 | `return_N < -1%` → 正确;`> +3%` → 错误 | |

**阈值依据**: 基于 A 股日均波动率(~1.5%)与交易成本(~0.6%)的工程化估算,实施阶段可配置化。

### 3.2 回测周期矩阵

| 周期 | N值 | 触发条件 | 数据需求 |
|---|---|---|---|
| 固定1日 | 1 交易日 | 评级日+1 | T+1 收盘价 |
| 固定1周 | 5 交易日 | 评级日+5 | T+5 收盘价 |
| 固定1月 | 20 交易日 | 评级日+20 | T+20 收盘价 |
| 动态 | 至下次变更 | `is_change=1` 的下次记录 | 两次评级变更之间的价格序列 |

### 3.3 核心指标定义

| 指标 | 公式 | 含义 |
|---|---|---|
| **准确率 (Accuracy)** | `Σis_correct / N` | 评级方向命中率 |
| **分级准确率** | 按 rating 分组计算 | 各档位的有效性 |
| **平均收益 (Avg Return)** | `mean(return_N)` | 评级后平均涨跌 |
| **方向偏离度** | `avg(|return_N|)` | 实际波动幅度 |
| **评级有效性分数** | 综合上述指标的 0-100 分 | 单个评级的 M8 分数 |

## 五、数据层接入(P0 输入消费)

### 5.1 从 P0 方案消费的输入

| P0 产出 | M8 消费方式 |
|---|---|
| 四维完整率基线(50.3%/100%/87%/47%) | 作为回测分析的"数据质量上下文",完整率<80%的标的回测结果单独标注 |
| 同花顺批量源(预期完整率95%+) | **不直接影响 M8**(M8 用历史 ratings_history) |
| **弹性系数 ε** | **直接消费**:作为 M8 数据扰动因子,输入 `WeightExperimentRunner` |
| 港股 fundamental 权重建议 | 留给 M9,M8 仅标注港股回测的"数据质量折算系数" |

### 5.2 数据质量折算系数(创新点)

```
当标的在某评级日的数据完整率 < 80% 时:
  effective_accuracy = raw_accuracy × data_quality_factor
  data_quality_factor = 0.7  # 默认折扣
  
例: 某评级 raw_accuracy=0.65, 完整率50% → effective=0.455
   标注"低质量数据回测,仅供参考"
```

目的:避免低质量数据期的回测结果误导 M9 优化决策。

#### 7.5.3 ⚠️ 代表性风险与补偿验证计划

**🔴 重大风险**: 时间跨度仅 4 天,远不足 90 天(一个季度)或 365 天(一个年度周期)。

**具体影响**:
1. **固定周期1月(20交易日)回测无法执行** — 评级日 T+20 超出当前数据范围
2. **跨周期(牛熊转换)有效性验证不可行** — 仅覆盖单一时间窗口
3. **评级档位 A/B+/A 无样本** — 高评级档位无法回测
4. **顺丰控股(002352)无变更** — 动态回测链为空
