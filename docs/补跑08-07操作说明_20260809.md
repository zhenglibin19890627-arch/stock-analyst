## 第二步：触发 08-07 补跑（粘贴一条命令，约 1 分钟操作 + 等待生成）

> **为什么不用页面上的"🚀 生成今日报告"按钮**：该按钮只能生成"今天"（08-09 周日）的报告，会生成一篇周末假报告，不符合补跑目的。所以改用下面这条指定日期的命令。

1. 在已打开的 `http://127.0.0.1:5000` 页面上，按键盘 **F12** 打开开发者工具
2. 点击开发者工具顶部的 **"Console"（控制台）** 标签
3. 把下面这一整段**完整复制**，粘贴到控制台空白处，按 **回车**：

```js
fetch('/api/daily-report/generate',{method:'POST',headers:{'Content-Type':'application/json'},body:JSON.stringify({date:'2026-08-07'})}).then(function(r){return r.json()}).then(function(d){alert('完成！success='+d.success+' 总数='+d.total+' 成功='+d.success_count+' 失败='+d.fail_count+' v5='+d.v5_count+' 降级='+d.legacy_count)})
```

4. 页面会显示"正在生成…"，耐心等待弹窗出现（5~15 分钟，期间页面不要刷新）
5. **资金流补采是自动包含的**：生成日报时系统会自动批量预取最近交易日的资金数据（含 08-07），无需单独操作
