## 一、测试范围与判定依据

### 1.1 评级边界权威定义（需求 §2.3.1）

| 档位 | 得分范围 | 含义 |
|---|---|---|
| 强烈推荐买入 | 85-100 | 强烈建议建仓或加仓 |
| 推荐买入 | 70-84 | 建议建仓或加仓 |
| 持有观望 | 50-69 | 保持现有仓位，等待信号 |
| 建议减仓 | 30-49 | 建议降低仓位 |
| 强烈建议卖出 | 0-29 | 建议清仓或大幅减仓 |

### 1.2 代码判定逻辑（实测锚点）

`_map_rating()`（[scoring_engine.py L909](file://c:\Users\zlb19\Desktop\Qoder%20cn\stock_analyst\modules\scoring_engine.py)）采用**降序遍历 + `>= info['min']` 命中即返回**，因此：
- 边界值 85/70/50/30 归入**上限档位**（如 85→强烈推荐买入，而非推荐买入）
- 浮点 84.99 归入**下限档位**（推荐买入）

### 1.3 历史兼容机制（实测锚点）

- `RATING_LEGACY_MAP`（[scoring_engine.py L67](file://c:\Users\zlb19\Desktop\Qoder%20cn\stock_analyst\modules\scoring_engine.py)）：A→强烈推荐买入 / B+→推荐买入 / B→持有观望 / C→持有观望 / D→建议减仓
- `normalize_rating(rating_str, total_score)`：有分数按分数精确映射，无分数按字符串映射
- 前端 `legacyMap`（[index.html L4137](file://c:\Users\zlb19\Desktop\Qoder%20cn\stock_analyst\templates\index.html)）做兜底渲染
