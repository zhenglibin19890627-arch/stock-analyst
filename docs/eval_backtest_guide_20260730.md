## 三、测评检查清单

### A. 评级有效性报告

| # | 检查项 | 关注点 |
|---|--------|--------|
| A1 | 总体准确率 | ≥50% 为基本有效（小样本波动大） |

| # | 检查项 | 关注点 |
|---|--------|--------|
| B1 | 买入区间命中率(T+20) | ≥40% 为合理（008基线） |
| B2 | 目标价命中率(T+20) | ≥30% 为合理 |
| B3 | 止损价命中率(T+20) | 越低越好（<30% 为佳） |

## 四、回测中心查看指南（零代码操作）

### 步骤 1：启动系统

```
双击打开命令行 → 输入以下命令 → 回车
cd "C:\Users\zlb19\Desktop\Qoder cn\stock_analyst"
python app.py
```

看到 `[OK] 服务就绪` 后，打开浏览器。

### 步骤 2：进入回测中心

1. 浏览器访问：**http://127.0.0.1:5000**
2. 点击顶部导航栏的 **🔬 回测中心** 标签

### 步骤 3：查看评级有效性报告

进入后默认显示「📊 市场报告」标签页：

1. 下拉选择 **A股** 或 **港股**
2. 页面自动加载「评级有效性报告」卡片：
   - **指标卡**：总回测数 / 总体准确率 / 正确 / 错误 / 动态准确率
   - **周期准确率表**：T+1日 / T+1周 / T+1月（判定数、正确、准确率、平均收益）
   - **分级准确率表**：5档评级各自的准确率 + T+1日/周/月均收益

> 💡 页面提示：T+1日受短期波动影响较大，建议结合周收益综合判断

### 步骤 4：查看价格建议命中率

评级有效性报告**下方**自动显示「价格建议命中率」区块：

1. **核心指标卡**：
   - 买入区间命中率(T+20)
   - 目标价命中率(T+20)
   - 止损价命中率(T+20)（越低越好）
   - 风险收益比（≥1.0 为良好）

2. **T+5 vs T+20 对比表**：各建议项在5天和20天内的命中率+平均命中天数

3. **分评级命中率表**：各评级的买入区间/目标价/止损价命中率

> 如显示"暂无数据"，点击 **▶ 运行价格建议回测** 按钮即可生成

### 步骤 5：手动重跑回测（可选）

如需更新回测数据：
1. 点击 **🔄 手动重跑回测** 按钮
2. 等待完成提示（约10-30秒）
3. 报告自动刷新

### 步骤 6：查看个股明细（可选）

1. 点击 **🔍 个股明细** 标签
2. 下拉选择一只股票
3. 查看该股票的历史评级 + 实际走势对比

### 步骤 7：导出数据（可选）

- 点击 **📥 导出Excel** → 下载回测数据表格
- 点击 **🖨️ 导出PDF** → 浏览器打印为PDF

## 五、结果判读参考

### 评级有效性判读

| 总体准确率 | 判读 |
|-----------|------|
| ≥60% | 评级方向性良好 |
| 50%~60% | 基本有效，需积累更多数据 |
| <50% | 需关注（小样本阶段可能是正常波动） |

### 价格建议判读

| 风险收益比 | 判读 |
|-----------|------|
| ≥1.5 | 优秀（目标命中远超止损） |
| 1.0~1.5 | 良好 |
| 0.5~1.0 | 一般，需观察 |
| <0.5 | 需关注（但小样本可能失真） |

### 小样本注意事项

- 当前仅 13 天评级历史（230条），结果波动大
- 010已标记"高偏差风险"记录（用当前评级套历史回测点）
- **建议**：积累至 60 天（约 2 个月）后再做策略级判断
- 可信样本：查看 `anchor_rating_date` 与回测点日期接近的记录
