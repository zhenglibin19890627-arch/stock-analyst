## 二、技术方案

### 当前逻辑（L711-719）

```
截取K线 → 技术面评分 → 映射评级 → 计算收益率 → 判定is_correct
```

### 目标逻辑

```
截取K线+基本面+资金面+消息面 → 调用 scoring_engine.analyze() → 四维评分 → 映射评级 → 计算收益率 → 判定is_correct
```

### 修改文件：modules/backtest_engine.py

**核心改动**：`run_historical_simulation()` 中技术面评分替换为调用 `data_adapter.load_stockdata_from_db()` + `scoring_engine.analyze()` 的四维评分。

**注意**：模拟回测的历史时间点可能没有当时的基本面/资金面/消息面数据（只有 K线）。处理策略：
- 优先调用 `load_stockdata_from_db` 构建完整 StockData
- 如果某维度数据不可用，analyze() 会自动降级（权重归一化），这是已有机制
- 模拟评级仍然有意义——它反映"如果当时有这些数据，评级会是什么"
