## 三、技术方案

### B10-FUNDAMENTAL（P0）：基本面字段补全

**目标**：将基本面完整度从 22% 提升至 ≥78%（9 个字段中至少 7 个有值）

**方案**：在 `data_collector.py` 中新增/增强基本面采集函数，调用 akshare 的财务分析指标接口补全缺失字段。

**推荐数据源**（开发需先验证可用性）：
- `ak.stock_financial_analysis_indicator(symbol="000858", start_year="2024")` — 可获取 ROE、毛利率、营收增长率、净利润增长率、资产负债率、流动比率、经营现金流/净利润等
- 备选：`ak.stock_financial_abstract_ths(symbol="000858")` — 同花顺财务摘要

**字段映射目标**：

| StockData 字段 | 含义 | 当前来源 | 补全来源 |
|---|---|---|---|
| pe_ttm | 滚动市盈率 | stock_individual_info_em | 保持 |
| pb | 市净率 | stock_individual_info_em | 保持 |
| roe | 净资产收益率 | 部分有 | stock_financial_analysis_indicator |
| gross_margin | 销售毛利率 | 多数缺失 | stock_financial_analysis_indicator |
| revenue_yoy | 营收同比增长 | 部分有 | stock_financial_analysis_indicator |
| net_profit_yoy | 净利润同比增长 | 部分有 | stock_financial_analysis_indicator |
| ocf_to_profit | 经营现金流/净利润 | 多数缺失 | stock_financial_analysis_indicator |
| debt_to_asset | 资产负债率 | 部分有 | stock_financial_analysis_indicator |
| current_ratio | 流动比率 | 部分有 | stock_financial_analysis_indicator |

**实现要点**：
1. 在 `data_collector.py` 新增函数 `fetch_fundamental_detail(symbol)` 调用财务指标接口
2. 在 `collect_stock_data()` 的基本面采集流程中，先取 `stock_individual_info_em` 的 PE/PB，再调用新函数补全其余字段
3. 写入 `raw_fundamental` 表（已有字段，无需改表）
4. 接口调用失败时静默降级（保留已有值，不覆盖为 None）
5. 仅对 A 股调用（港股基本面数据源另行处理）

---

### B10-HOLDER（P1）：股东增减持接入

**目标**：消息面完整度从 50% 提升至 100%

**方案**：
1. 在 `data_collector.py` 新增函数 `fetch_holder_increase(symbol)` 获取近 30 天大股东/高管增减持信息
2. 在 `raw_fundamental` 表或新建 `raw_holder_change` 表存储结果
3. 修改 `data_adapter.py` L388，从数据库读取 `holder_increase` 替代硬编码 None

**推荐数据源**（开发需先验证可用性）：
- `ak.stock_inner_trade_xq(symbol="000858")` — 雪球内部交易（高管增减持）
- 备选：`ak.stock_ggcg_em(symbol="000858")` — 股东增减持（东方财富）

**实现要点**：
1. 判定逻辑：近 30 天内存在增持记录 → `True`，存在减持记录 → `False`，无记录 → `None`
2. 采集频率：随批量分析触发，无需独立定时器
3. 接口不可用时返回 None（降级策略已定义：权重归零）
4. 港股暂不支持（保持 None）

---

### B10-CAPITAL-LABEL（P2）：资金面数据受限标注

**目标**：用户能清楚知道资金面 67% 的原因

**方案**（二选一，开发评估后选最简方案）：

**方案 A（推荐）**：在 `data_adapter.py` 构建 StockData 时，若 `north_net_buy` 为 None，在 `extra` 字段中写入提示：
```python
extra['capital_note'] = '北向资金/两融数据源暂不可用，资金面评分仅基于主力资金流向'
```
前端看板/报告页展示此提示。

**方案 B**：在 `scoring_engine.py` 的 `data_warnings` 中追加说明文字。

**实现要点**：
1. 不修改数据采集逻辑（north/margin 保持现状）
2. 仅在展示层增加说明
3. 前端改动最小化（利用已有的 data_warnings 展示通道）
