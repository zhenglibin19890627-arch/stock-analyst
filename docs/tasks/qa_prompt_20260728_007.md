### TC8：命中率逻辑合理性验证

**测试步骤**：抽样检查命中判定逻辑是否正确

**验证命令**：
```
C:\Users\zlb19\AppData\Local\Programs\Python\Python312\python.exe -c "
import sqlite3, json
c = sqlite3.connect('stock_analyst/stock_analyst.db')
c.row_factory = sqlite3.Row
# 取5条记录，验证命中逻辑
rows = c.execute('SELECT * FROM price_backtest_results WHERE market="a_stock" ORDER BY RANDOM() LIMIT 5').fetchall()
for r in rows:
    buy_low = r['buy_range_low']
    buy_high = r['buy_range_high']
    target = r['target_price']
    t20_max = r['t20_max_high']
    t20_min = r['t20_min_low']
    hit_buy = r['t20_hit_buy_range']
    hit_tgt = r['t20_hit_target']
    print(f'buy=[{buy_low},{buy_high}] tgt={target} T20:high={t20_max} low={t20_min} hit_buy={hit_buy} hit_tgt={hit_tgt}')
    # 验证逻辑一致性
    if t20_max is not None and t20_min is not None:
        expected_buy = 1 if (t20_min <= buy_high and t20_max >= buy_low) else 0
        expected_tgt = 1 if (t20_max >= target) else 0
        assert hit_buy == expected_buy or hit_buy is None, f'buy range mismatch: expected={expected_buy} got={hit_buy}'
        assert hit_tgt == expected_tgt or hit_tgt is None, f'target mismatch: expected={expected_tgt} got={hit_tgt}'
print('PASS: hit logic verified for 5 samples')
"
```

**预期结果**：5条抽样记录的命中逻辑与 high/low 触及判定一致
