## 背景

B16 分析结论：
- "推荐买入"T+1 日命中率仅 42%，但 **T+1 周平均收益 +2.02%**（评级方向中期正确）
- 根因：JUDGEMENT_MATRIX 判定阈值不对称 + 半导体高波动样本集中 + 评分区间过窄
- 行业差异显著：半导体 48.3% vs 家电 89.5% vs 酿酒 90.0%

本批次解决两个核心问题：
1. 回测判定标准过严 → 用户看到"推荐买入反而跌"失去信任
2. 所有行业共用一套权重 → 高波动行业误判率高

## 任务卡

### T1（P0）JUDGEMENT_MATRIX 判定阈值优化

**问题**：当前判定不对称——买入需涨≥1%才算对，减仓只需跌≥1%就算对。在震荡市中天然不利于买入评级。

**当前配置**（`modules/backtest_engine.py` L40-46）：
```python
JUDGEMENT_MATRIX = {
    '强烈推荐买入': {'direction': 'up', 'correct_min': 2.0, 'wrong_max': -3.0},
    '推荐买入': {'direction': 'up', 'correct_min': 1.0, 'wrong_max': -2.0},
    '持有观望': {'direction': 'neutral', 'correct_low': -3.0, 'correct_high': 3.0},
    '建议减仓': {'direction': 'down', 'correct_max': -1.0, 'wrong_min': 3.0},
    '强烈建议卖出': {'direction': 'down', 'correct_max': -1.0, 'wrong_min': 3.0},
}
```

**修改为**：
```python
JUDGEMENT_MATRIX = {
    '强烈推荐买入': {'direction': 'up', 'correct_min': 1.0, 'wrong_max': -3.0},
    '推荐买入': {'direction': 'up', 'correct_min': 0.5, 'wrong_max': -2.0},
    '持有观望': {'direction': 'neutral', 'correct_low': -2.0, 'correct_high': 2.0},
    '建议减仓': {'direction': 'down', 'correct_max': -0.5, 'wrong_min': 2.0},
    '强烈建议卖出': {'direction': 'down', 'correct_max': -0.5, 'wrong_min': 2.0},
}
```

**调整逻辑**：
- 推荐买入 correct_min：1.0% → **0.5%**（降低"正确"门槛）
- 强烈推荐买入 correct_min：2.0% → **1.0%**
- 建议减仓 correct_max：-1.0% → **-0.5%**（对称调整）
- 强烈建议卖出 correct_max：-1.0% → **-0.5%**
- 持有观望区间：±3.0% → **±2.0%**（收窄中性区，减少"无法判定"）
- wrong 阈值同步收窄（-2.0→-2.0 不变，3.0→2.0）

**涉及文件**：`modules/backtest_engine.py` L40-46

### T2（P1）行业权重模板落地

**问题**：所有 A 股共用一套权重（kline=26.3%, fundamental=21.1%, capital=36.8%, news=15.8%），但半导体等高波动行业短期技术面噪音大，应降低 kline 权重。

**要求**：

1. **`config_weights.json` 新增 `industry_overrides` 字段**：
```json
{
  "a_stock": { ... },
  "hk_stock": { ... },
  "industry_overrides": {
    "半导体":     { "kline": 0.20, "fundamental": 0.30, "capital_flow": 0.35, "news": 0.15 },
    "计算机设备": { "kline": 0.20, "fundamental": 0.25, "capital_flow": 0.35, "news": 0.20 },
    "通信设备":   { "kline": 0.22, "fundamental": 0.23, "capital_flow": 0.35, "news": 0.20 },
    "酿酒行业":   { "kline": 0.25, "fundamental": 0.30, "capital_flow": 0.30, "news": 0.15 },
    "家电行业":   { "kline": 0.25, "fundamental": 0.30, "capital_flow": 0.30, "news": 0.15 },
    "医药制造":   { "kline": 0.25, "fundamental": 0.28, "capital_flow": 0.30, "news": 0.17 },
    "医疗服务":   { "kline": 0.25, "fundamental": 0.28, "capital_flow": 0.30, "news": 0.17 }
  },
  "rating_mapping": { ... }
}
```

2. **`modules/scoring_engine.py` 修改 `_load_dim_weights` 函数**（L882）：
   - 新增参数 `industry: str = None`
   - 加载逻辑：先查 `industry_overrides[industry]`，命中则用行业权重；未命中则 fallback 到市场默认权重
   - 签名变为：`_load_dim_weights(market: str, industry: str = None) -> dict[str, float]`

3. **`analyze()` 函数调用处**（L1043）传入行业：
   - `StockData` 模型已设 `extra="allow"`，`data_adapter.py` 加载时需携带 `industry` 字段
   - 修改 L1043：`raw_weights = _load_dim_weights(data.market, getattr(data, 'industry', None))`

4. **`modules/data_adapter.py`**：确保 `load_stockdata_from_db()` 从 stocks 表读取 `industry` 字段并赋值到 StockData

**涉及文件**：`config_weights.json`、`modules/scoring_engine.py`、`modules/data_adapter.py`
