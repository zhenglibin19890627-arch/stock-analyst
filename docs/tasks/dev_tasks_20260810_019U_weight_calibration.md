## 一、需求与范围

### T1 候选权重方案设计（研究型）
1. 依据 IC 报告 §6.1/§6.4 的方向性观察，设计 1~3 套 A 股候选权重方案（四维之和=1，保留现有 rating_mapping 与降级机制不动）。报告倾向性线索：资金面让渡权重优先给予基本面；技术面/消息面维持观察。
2. 方案须附设计依据说明（引用 IC 数字），并明确声明受 R-1 样本量约束。
3. **仅 A 股**：港股样本 52~75 行、每日横截面 1~6 行，IC 报告 §6.2 明确"不基于港股 IC 调整权重"——港股权重本批不动。

### T2 模拟回测验证框架（研究型，核心环节）
1. 用 `analysis_results` 历史 448 行（2026-07-16~08-07）+ `raw_kline`，模拟各候选权重下的 total_score 重算与 T+1/T+5 表现对比（现权重 vs 候选权重）。
2. 对比指标须含：新旧权重下综合分 Rank IC（沿用 019T T1 的逐日横截面方法、秩+Pearson 手工 Spearman 实现、零新依赖）、评级分布迁移（rating_mapping 80/65/50/30 阈值下各档人数变化）、资金面填充行敏感性并列披露（沿用 019T 口径）。
3. 模拟全程只读（`mode=ro`）或 `:memory:` 构造，**不写生产库、不改生产代码**。
4. 产出模拟验证报告（docs/reports/），须披露样本量与置信边界（R-1），结论限于"候选方案间相对优劣"，不得宣称统计显著。

### T3 权重生效与回滚预案（工程型，条件触发）
1. **仅在监理依据模拟报告裁定调整后执行**：修改 `config_weights.json` a_stock.weights（修改前先备份配置文件），更新 `_更新时间`/`_备注` 溯源字段。
2. 生效机制核对：配置文件修改后无需重启、下次分析自动生效（config_weights.json `_说明`），生效时点须避开 16:10/16:30 与周日 20:00 窗口。
3. 回滚预案：上线后若后续 IC 监测显示调整方向与实盘反向（参照 O2-E 教训），一键恢复备份配置。预案须写入交付文档。

## 三、验收标准（共 7 条）

1. **候选方案产出**：1~3 套 A 股候选权重方案 + 设计依据说明，引用 IC 报告数字，声明 R-1 约束；仅 A 股。
2. **模拟框架零侵入**：模拟回测全程只读/`:memory:`，不改生产代码、不写生产库、不新增依赖（沿用零新依赖红线）。
3. **模拟报告产出**：docs/reports/ 下模拟验证报告，含新旧权重综合分 IC 对比、评级分布迁移、填充行敏感性并列披露、样本量与置信边界声明。
4. **生效前置裁定**：config_weights.json 不得在监理裁定前被修改（硬性）；T3 为条件触发，监理不裁定调整则本批以"方案+验证报告"交付关闭。
5. **生效可回滚**：若裁定调整，须先备份原配置、更新溯源字段，交付文档含一键回滚步骤（零代码用户可独立执行）。
6. **定时任务安全**：全部写操作（含配置文件修改）避开 16:10/16:30 与周日 20:00 窗口。
7. **零数据破坏与红线**：B24 不触碰 advisor.generate_advice；B11 禁止点击个股详情触发实时分析写库；模拟对照一律备份/只读/`:memory:` 构造。

## 四、风险登记（供架构评审）

1. **R-1 样本量薄弱（最高风险）**：448 行、29 只、17 个交易日，任何候选权重的模拟优劣判断都可能过拟合当期噪声。缓解：方案保守（小幅微调优先于大幅重排）、报告强制披露置信边界、上线后持续 IC 监测 + 回滚预案。
2. **R-2 O2-E 重演风险**：上一轮调整因与股票池特征反向而回滚。本批以模拟验证为生效前提即为针对性缓解，评审须确认模拟方法足以捕捉"与股票池数据特征反向"这类信号。
3. **R-3 评级分布迁移**：权重变化直接改变 total_score 分布，80/65 阈值附近的个股评级可能跳档，影响前端展示与优化器准确率基线。模拟报告须量化披露迁移规模。
4. **R-4 优化器耦合**：权重生效与周日 20:00 M9 优化器的准确率基线联动，上线时点须避开优化窗口（同 019T R-2 机制）。
5. **R-5 industry_overrides 交互**：行业覆盖权重独立于市场级权重生效，市场级调整若不同步评估行业层，可能出现"市场级向基本面倾斜、行业层仍重仓资金面"的方向冲突。
6. **R-6 数据增长窗口**：今日 16:10 后 analysis_results 将新增样本，模拟基准日须冻结披露（建议以模拟执行时点库存快照为准并记录行数）。

## 五、开放项（架构评审裁定，重大项升级监理）

- **A. industry_overrides 同步**：市场级权重调整后，7 个行业覆盖是否同批评估/调整？PM 建议至少做影响分析（R-5），评审定夺。

- **C. 监测与回滚触发条件**：上线后 IC 监测的频率、观察期与回滚触发规则如何定义？评审给预案。
- **D. 港股权重**：本批明确不动；何时重估（样本量门槛建议）由评审登记。
