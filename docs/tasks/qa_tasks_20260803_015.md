## 一、015 功能概述

本批次为**纯前端 UX 优化 + 1处后端逻辑修正**，解决 UX 评价报告剩余的 7 项痛点。以下为 PM 核查后整理的功能说明与接口契约，**供 QA 独立设计测试用例参考**（不替代 QA 自行阅读代码）。

### 涉及文件

| 文件 | 改动 |
|---|---|
| `templates/index.html` | U1~U6 前端全部改动 + U7 前端展示 |
| `app.py` | U7 仅 L996-L1019（data_quality 推导逻辑） |

### U1（#9）持仓成本小数位规整
- 持仓管理页成本价统一 2 位小数（自选股页此前已做，本次仅修持仓页）
- 关键位置：持仓渲染区 `var costDisplay` 应含 `.toFixed(2)`

### U2（#6）今日报告 / 盘中快报 功能说明
- 每日报告视图区（`#view-daily`）添加持久说明栏，区分两种报告
- 说明文字放在 `#dailyContent` **外部**（避免被 `loadLatestDailyReport()` 替换）

### U3（#10）回测中心一句话总结
- `loadBacktestMarketReport()` 渲染顶部增加动态摘要条
- 数值从回测 API 返回数据动态提取（总体准确率、T+1日准确率、最强评级档）

### U4（#4）专业术语悬浮解释
- 新增 `_dimFactorTooltips` 对象（约 L5163），含4维度×关键因子通俗解释
- `_renderDimensionCard()` 为标签添加 `title` 属性 + `cursor:help`
- 覆盖：RSI、PE、PB、ROE、主力净占比等

### U5（#7）预警功能入口显化
- 预警下拉面板增加「➕ 添加预警规则」+「⚙ 管理规则」操作栏
- 新增弹窗 `#alertRuleModal`（约 L992），表单字段：`alertRuleType`/`alertRuleScope`/`alertThresholdInput`/`alertStockSelect`
- **对接现有 API（禁止新增后端路由）**，接口契约如下：

| 方法 | 路由 | 入参 | 说明 |
|---|---|---|---|
| GET | `/api/alerts/rules` | — | 查询全部规则（含全局+个股） |
| POST | `/api/alerts/rules` | `{rule_type, stock_id?, threshold?, enabled?}` | 新增规则 |
| PUT | `/api/alerts/rules/<id>` | `{threshold?, enabled?}` | 修改规则 |
| DELETE | `/api/alerts/rules/<id>` | query `force=1` 物理删除 | 软删除（enabled=0） |

> `rule_type` 仅支持 3 种：`rating_change`（评级变动）/ `score_below`（评分跌破）/ `capital_outflow`（资金流出）

### U6（#3）自选股按钮精简与操作引导
- 每行 8 按钮 → 3 个可见（⚡ 一键分析 + 📊 报告 + ⋯ 更多）
- 新增 `oneClickAnalyze(id, symbol, market)` 函数（约 L2223）：依次调用 `/api/collect/{id}` → `/api/stocks/{id}/analyze` → `/api/stocks/{id}/advise`，带进度条（300秒超时）
- 「⋯ 更多」下拉含：查看数据 / 加入持仓 / 编辑 / 删除（功能零丢失）
- 首次操作引导：当 `latest_price == null` 时提示

### U7（#5）数据完整度显示口径统一
- **app.py L996-L1019**：无 `data_completeness` 字段时默认值从 `1.0`（100%）改为 `None`
- **前端**：`d.val === null/undefined` 时显示「已采集」（灰色），不再误显 100%

### 逐项测试用例指引

#### TC1 — U1 持仓成本小数位（风险：极低）
- [ ] 打开持仓管理页，检查每只股票成本价是否为 **2位小数**（如 60.78 非 60.784）
- [ ] 「已修正」标签是否正常显示
- [ ] 自选股页成本价不受影响（仍为2位小数）
- [ ] 成本价为 null 时显示「--」

#### TC2 — U2 报告说明文字（风险：极低）
- [ ] 进入每日报告页，检查是否有两种报告的说明文字
- [ ] 说明文字**零代码用户能看懂**（区分"盘后汇总" vs "盘中实时"）
- [ ] 点击「查看最新报告」后说明文字**不被覆盖消失**
- [ ] 三个按钮（生成今日报告/盘中快报/查看最新报告）功能正常

#### TC3 — U3 回测一句话总结（风险：低）
- [ ] 进入回测中心页，等待数据加载，检查顶部是否有「一句话总结」摘要条
- [ ] 摘要数值**随实际数据动态变化**（非硬编码）——对比回测表格中的总体准确率

#### TC4 — U4 术语悬浮解释（风险：低）

- [ ] 悬浮显示**通俗易懂**的解释文案（如"PE=市盈率..."）
- [ ] 指标**数值显示**不受影响（不因 title 改变数值）
- [ ] 页面布局不受影响
- [ ] 至少验证技术面(RSI/均线)、基本面(PE/ROE)、资金面(主力净流入)、消息面(情绪)各1项

#### TC5 — U5 预警功能入口（风险：中）★重点测试

- [ ] **验证写入**：点击「⚙ 管理规则」或 GET `/api/alerts/rules`，确认规则出现在列表
- [ ] **实际删除规则**：删除刚添加的规则，确认从列表移除（软删除 enabled=0）
- [ ] 现有预警通知、已读、徽标功能不受影响
- [ ] **后端路由核查**：确认 015 未在 app.py 新增任何 `@app.route`（红线）
- [ ] 弹窗关闭：点击遮罩层或关闭按钮可关闭弹窗

#### TC6 — U6 按钮精简（风险：中）★重点测试
- [ ] 自选股页每行可见按钮 ≤ 4 个（⚡ 一键分析 + 📊 报告 + ⋯ 更多）
- [ ] 点击「⋯ 更多」下拉展开，含：查看数据/加入持仓/编辑/删除（**4项功能无丢失**）
