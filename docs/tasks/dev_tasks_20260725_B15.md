## 任务卡

### T1（P0）盈亏显示一致性修复

**问题**：持仓页显示"总浮动盈亏 5116.30"（绿色、无负号），看板页显示"浮动盈亏 ¥-5116.30（-3.52%）"（黑色）。同一数据两页矛盾。

**要求**：
- 统一数据源：两页盈亏必须取自同一计算逻辑（以看板页 `¥-5116.30` 格式为准）
- 统一颜色规则：**亏损 = 绿色 + 负号**，**盈利 = 红色 + 正号**（A 股习惯：红涨绿跌）
- 统一格式：`¥{+/-}{金额}（{+/-}{百分比}%）`
- 持仓页"总浮动盈亏"卡片与看板页"账户汇总"必须数值完全一致

**涉及文件**：`templates/index.html`（持仓页渲染 + 看板页渲染）、`app.py`（若涉及 API 返回格式）

---

### T2（P1）日报生成复用批量分析结果

**问题**：用户先点"批量分析"（293 秒），再点"生成日报"（519 秒），日报又把全部股票重新采集+评分一遍，总等待 14 分钟。

**要求**：
- 日报生成时，若该股票在**当日内**已有成功的分析结果（analysis_results 表有当日记录），直接复用，**跳过网络采集+重新评分**
- 仅对当日无分析结果的股票执行采集+评分
- 日报生成页面显示复用统计：`"复用 X 只 / 新采集 Y 只"`
- 若用户强制需要全量刷新，保留"强制刷新"选项（checkbox 或按钮）

**涉及文件**：`modules/daily_report.py`、`app.py`（日报 API）、`templates/index.html`（前端提示）

---

### T3（P1）详情页投资建议默认展示

**问题**：进入个股详情页，"投资建议详情"区域为空白，必须手动点"刷新报告"才出现内容。

**要求**：
- 详情页加载时，若 DB 中已有该股票的分析报告（analysis_results 表有记录），**直接渲染**投资建议内容，无需用户额外点击
- 仅当 DB 无记录时，显示"暂无报告，请点击生成"提示按钮
- "刷新报告"按钮保留，用于用户主动更新

**涉及文件**：`templates/index.html`（详情页 JS 加载逻辑）、`app.py`（若需新增/调整查询 API）

---

### T4（P2）数据不足醒目标注

**问题**：港股资金面完整度 0%、科创板基本面 0%，但评分和评级照常显示，用户误以为可信。

**要求**：
- 当任一维度完整度 = 0% 时，在该维度评分旁显示醒目警告：`⚠️ 数据缺失，此项仅供参考`
- 当**两个及以上维度**完整度 = 0% 时，在总评级旁追加醒目提示：`⚠️ 数据严重不足，评级仅供参考，不建议作为操作依据`
- 提示样式：橙色/黄色背景 + 深色文字，与正常评分视觉区分明显
- 不影响评分计算逻辑本身（降级策略已在引擎层处理）

**涉及文件**：`templates/index.html`（详情页/看板页渲染）
