### 关键发现

| 指标 | 数值 |

### 根因结论
1. **基本面** avg 50.7（四维最低），实际max仅76.4 vs 理论96.4，≥80分股票0只
2. **资金面** 权重最高(40%)但 avg 仅51.2，子项 north/margin 上限仅85
3. **技术面** vol_ratio 上限仅75（子项最低）
4. 不是"理论上不可能过80"，而是无股票能同时让四维接近上限
