## 一、需求与范围

本批次三项任务，T1 为研究型（只读、不改生产逻辑），T2/T3 为工程型（改代码+自测）：

### T1 维度 IC 有效性体检（研究型）
1. 用历史数据回答："四个维度（技术面/基本面/消息面/资金面）的得分，到底哪个真的能预测未来收益？"
2. 方法基线（架构评审可优化）：以 `analysis_results` 表维度分为因子，关联 `raw_kline` 计算 T+1/T+5/T+20 未来收益，计算 Spearman 秩相关（Rank IC）及 IC 均值/ICIR，A 股与港股分开统计。
3. **本阶段只做维度级**。子项级（如 main_capital、ma 单独算 IC）因历史子项分未落库而无法追溯，是否新增落库见开放项 B。
4. **T1 不改任何生产代码与权重**。产出 IC 分析报告（写入 docs/reports/），权重是否调整由监理依据报告另行裁定（可作 019U 候选）。

### T2 遗留项⑨修复：资金面缺位不得映射高分
1. 缺陷定位（PM 已核实）：`modules/scoring_engine.py` `score_main_capital()`（约 L766-788）——`main_net_inflow is None` → D02 填充 `NEUTRAL_INFLOW=0.0` → 落入 `inflow >= 0` 档返回 **85.0 分**。资金面维度权重 A 股 39.85%，缺数据反而近似满分，偏多偏差成立。
2. 修复目标：**区分"实测流入恰为 0"与"数据缺失填充 0"**；缺失场景不得产生偏多得分。
3. 修复方案候选（架构评审裁定）：a. 缺失返回真中性 50 分；b. 缺失触发 A 类子项权重归零（维度内归一化补足，复用既有 Q03 降级机制）；c. 其他。PM 倾向 b（缺失=无信息，不应占权重），但尊重评审结论。
4. **同类问题一并评估（开放项 A）**：`score_north_capital()` 缺失返回 70.0（约 L795）、`score_margin_capital()` 缺失返回 68.0（约 L816）属同一"缺失偏暖"家族，是否同批修复由架构评审裁定。
5. **硬边界**：有实测数据的行，评分行为不得有任何变化（回归断言）。

### T3 回测判定矩阵引入基准对比
1. 目标：M8 回测从"绝对收益判定"升级为"超额收益（alpha）判定"——A 股对标沪深300（000300），港股对标恒生指数（HSI）。
2. 数据基线（PM 已核实）：`index_kline` 表已有 5 个 A 股指数各 309 行日 K（2025-04-29 ~ 2026-08-05），含 000300；**但恒指 HSI/HSTECH 在 `index_collector.py` INDEX_LIST 有配置，库中却无任何数据**——港股基准需先修复采集链路（`ak.stock_hk_index_daily_em`，可用性待实测）。
3. schema 扩展：`backtest_results` 新增基准收益与 alpha 列，沿用 backtest_engine 既有"安全追加列、幂等迁移"模式。
4. 判定矩阵升级方案（架构评审裁定）：PM 建议在原绝对收益判定之外，增加 alpha 判定列（如 alpha_1d/1w/1m 与 is_correct_alpha），**不直接推翻原 is_correct**，保留口径可对照。
5. 存量 820 行 backtest_results 是否追溯补算 alpha，见开放项 C。
6. 前置任务：排查恒指采集为何从未入库；核查指数刷新链路时效性（库内 A 股指数数据止于 08-05，最近缺数据交易日为 08-06/08-07（08-08 为周六）【PM 勘误 ②】，刷新机制需一并核查）。
