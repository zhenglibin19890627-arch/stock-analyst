## 四、技术方案

### 核心思路：让 v5 子评分函数的 detail 传递到 `_build_v5_factors`

**修改方案（两步）**：

#### 步骤1：scoring_engine.py — AnalysisResult 增加 dim_details 字段

在 `analyze()` 函数 L1119 构造 AnalysisResult 前，将 `dim_results` 的因子明细提取为精简版 dict，附加到结果中。

由于 AnalysisResult 是 Pydantic 模型（不能随意加字段），**建议方案**：在 analyze() 返回 result 后，用 `result.dim_details = {...}` 动态属性附加（利用 extra="allow" 特性），或在 advisor.py `_convert_v5_to_legacy` 中重新调用子评分函数获取 detail。

**推荐：方案A（改 advisor.py，不动 scoring_engine.py）**

#### 方案A：advisor.py `_convert_v5_to_legacy` 中直接从 StockData 构建因子

在 `_convert_v5_to_legacy`（L538）中，除了从 v5_result 取分数外，**额外读取 StockData 原始字段**，构建前端期望的 factors：

```python
# 在 _convert_v5_to_legacy 中，获取原始 StockData
from modules.scoring_engine import analyze_from_db

# 或从 v5_result 中已有的数据
stock_data = _get_stock_data_for_factors(stock_id)  # 从DB读K线/基本面数据

factors = _build_v5_factors_rich(stock_data, dim_key)  # 新函数，输出完整因子
```

#### 方案B（推荐）：改写 `_build_v5_factors`（advisor.py L604）

将 `_build_v5_factors` 从仅读 v5_result 元数据，**改为从 DB 读取原始数据构建因子明细**：

```python
def _build_v5_factors(stock_id, v5_result, dim_key):
    """从 DB 读取原始数据，构建前端可读的 factors"""
    factors = {}
    
    # 维度总分（保留原有）
    score_map = {'kline': v5_result.technical_score, ...}
    if score_map.get(dim_key) is not None:
        factors['dimension_score'] = f'{score_map[dim_key]:.1f}'
    
    # 完整度（保留原有）
    ...
    
    # ★ 新增：从 DB 读取原始数据构建因子明细
    conn = get_connection()
    c = conn.cursor()
    
    if dim_key == 'kline':
        # 读最新K线
        c.execute('SELECT ... FROM raw_kline WHERE stock_id=? ORDER BY trade_date DESC LIMIT 1', (stock_id,))
        row = c.fetchone()
        if row:
            ma5, ma20 = row['close_5ma'] or 0, row['close_20ma'] or 0
            factors['ma_trend'] = f'{"多头排列" if ma5 > ma20 else "空头排列"}(MA5={ma5:.2f}{" > " if ma5>ma20 else " < "}MA20={ma20:.2f})'
            rsi = row.get('rsi_14') or row.get('rsi')
            if rsi:
                factors['rsi_status'] = f'{"超买" if rsi>70 else "超卖" if rsi<30 else "正常"}({rsi:.1f})'
            ...
    
    elif dim_key == 'fundamental':
        c.execute('SELECT ... FROM raw_fundamental WHERE stock_id=? ORDER BY report_date DESC LIMIT 1', (stock_id,))
        row = c.fetchone()
        if row:
            pe = row.get('pe_ratio')
            if pe: factors['pe_ratio'] = f'{pe:.2f}'
            roe = row.get('roe')
            if roe is not None: factors['roe'] = f'{roe:.2f}%'
            ...
    
    conn.close()
    return factors
```
