## 评价流程

### 第一步：启动体验

1. 执行启动命令
2. 评价：启动是否顺畅？有无报错？提示信息是否友好？
3. 打开浏览器访问 http://127.0.0.1:5000

### 第二步：逐页浏览（核心评价）

依次点击每个标签页，以用户视角评价：

| 页面 | 评价要点 |
|---|---|
| **自选股看板** | 信息是否一目了然？评分/评级是否易理解？颜色/图标是否直观？ |
| **评级列表** | 排序/筛选是否好用？评级名称是否通俗？ |
| **每日报告** | "生成今日报告"和"盘中快报"按钮是否醒目？报告内容是否看得懂？ |
| **单只详情** | 点击某只股票进入详情，四维雷达图/价格建议/操作建议是否清晰？ |
| **回测中心** | 回测结果是否可理解？准确率数字是否有参考价值？ |
| **智能预警** | 规则设置是否简单？通知是否明显？ |
| **持仓管理** | 添加/编辑持仓是否方便？盈亏展示是否清晰？ |

### 第三步：核心操作体验

实际执行以下操作（不是只看，是真的点）：

1. **生成盘中快报**：点击"📊 盘中快报"按钮 → 等待 → 查看结果
2. **查看单只股票详情**：从列表点进某只股票 → 查看评分/建议/价位
3. **查看日报**：浏览最新日报内容
