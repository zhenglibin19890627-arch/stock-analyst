## 三、详细实现要求

### 任务1：重写 modules/price_advisor.py（~500行）

#### 1.1 操作建议状态机（决策点1）

新增 _determine_action_by_state(close, cost_price, take_profit, stop_loss, rating) 函数：

状态定义：
- S1: close >= take_profit（已超目标）
- S2: cost_price < close < take_profit（浮盈中）
- S3: stop_loss <= close <= cost_price（浮亏中）
- S4: close < stop_loss（已破止损）

状态x评级矩阵（详见架构师报告§1.2）。核心规则：S4禁止出现'加仓'。

无持仓场景也需感知价位：
- close < buy_range_low -> '当前价低于买入区间，可逢低买入'
- buy_range_low <= close <= buy_range_high -> '当前价在买入区间内，可按计划买入'
- close > buy_range_high -> '当前价高于买入区间，建议等待回调'

#### 1.2 止盈价动态化（决策点2）

方案C 双约束公式：
```
固定止盈价 = cost_price * (1 + target_gain)
技术阻力位 = min(boll_upper, ma60)（取最近阻力位，必须>close）
最低止盈价 = cost_price * (1 + min_target_gain)
止盈价 = max(最低止盈价, min(固定止盈价, 技术阻力位))
```

新增常量 MIN_TARGET_GAIN（最低目标涨幅）：
```
MIN_TARGET_GAIN = {'强烈推荐买入': 0.08, '推荐买入': 0.06, '持有观望': 0.04, '建议减仓': 0.03, '强烈建议卖出': 0.02}
```

#### 1.3 网格价位（决策点3）

无持仓买入网格（3档，ATR*0.8间距）：
```
第一买入位 = buy_range_low（仓位40%）
第二买入位 = buy_range_low + ATR*0.8（仓位35%）
第三买入位 = buy_range_high（仓位25%）
```

有持仓网格（1补+2-3减，ATR间距）：
```
补仓位 = max(stop_loss + ATR*0.5, close - ATR*1.0)（仓位10%）
第一减仓位 = cost_price（仓位30%，回本减仓）
第二减仓位 = cost_price + ATR*0.6（仓位50%）
最终止盈位 = take_profit（仓位100%）
```

输出结构：
```
'grid': [
    {'level': 1, 'price': 52.00, 'pct': 40, 'type': 'buy', 'label': '第一买入位'},
    ...
]
```

#### 1.4 资金面转化（决策点4）

新增 _parse_capital_factors(factors) 解析资金面文本为结构化数据。
新增 _classify_capital_signal(parsed) 分类7档信号(-2~+2)。
修饰词方案：强信号前置，弱信号后置。

资金面因子来源：advice_result['dimensions']['capital_flow']['factors']
需解析的文本格式：
- main_trend: '主力净流入21800万元' -> 21800
- consecutive: '连续净流入2日' -> +2
- super_large: '超大单净8000万元(流入)' -> +8000

#### 1.5 交易流水分析（决策点5）

新增 _analyze_trade_records(stock_id) 函数：
- 从 trade_records 表读取买卖记录
- 维度1：加仓节奏（买入间隔天数，频繁/分批/低频）
- 维度2：成本趋势（递减=好/递增=差）
- 维度3：买卖时机（FIFO配对，胜率+平均盈亏）
- 数据不足（<2笔买入）时 available=False

#### 1.6 向后兼容

保留所有现有输出字段（take_profit/stop_loss/cost_price/current_close/profit_pct/disclaimer）。
新增字段：grid, capital_signal, trade_analysis, state, action_suggestion（动态）。

#### 无持仓展示
- 标题+评级+建议仓位+当前价
- 核心数据行：买入区间/目标价/止损价/操作建议

- 已破止损=红色(pa-down)

- 减仓位=橙色(pa-reduce)
