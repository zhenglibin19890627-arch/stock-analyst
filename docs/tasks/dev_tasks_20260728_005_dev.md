## 三、开发任务详细分解

### 任务 1：新建 `modules/price_advisor.py`（~250行）

#### 1.1 主函数签名

```python
def generate_price_advice(stock_id, advice_result):
    """
    根据评级建议结果，生成价格建议。
    后处理集成：在 generate_advice 返回后调用，不修改 generate_advice。

    Args:
        stock_id: 股票 ID
        advice_result: generate_advice 的返回字典（含 rating/has_position/latest_close 等）

    Returns:
        dict: 价格建议字典，结构见 §1.2
    """
```

#### 1.2 输出结构

**无持仓状态**：
```json
{
    "available": true,
    "has_position": false,
    "position_pct": 50,
    "buy_range_low": 15.20,
    "buy_range_high": 16.00,
    "target_price": 18.50,
    "stop_loss": 14.80,
    "current_close": 15.85,
    "expected_gain_pct": 16.7,
    "max_loss_pct": -6.6,
    "disclaimer": "仅供参考，不构成投资建议"
}
```

**有持仓状态**：
```json
{
    "available": true,
    "has_position": true,
    "take_profit": 18.00,
    "stop_loss": 13.95,
    "cost_price": 15.00,
    "current_close": 15.85,
    "profit_pct": 5.7,
    "action_suggestion": "加仓20%",
    "disclaimer": "仅供参考，不构成投资建议"
}
```

**数据不足/停牌**：
```json
{
    "available": false,
    "reason": "停牌或数据不足"
}
```

#### 1.3 算法实现（严格按架构师评审 §三）

**ATR 计算**：
```
TR = max(high - low, |high - prev_close|, |low - prev_close|)
ATR(14) = TR 的 14 日简单移动平均
SQL: SELECT high, low, close FROM raw_kline WHERE stock_id=? ORDER BY trade_date DESC LIMIT 15
降级: raw_kline 不足15天用已有天数; 不足2天 → ATR 不可用
```

**买入价位区间（无持仓）**：
```
买入中枢 = MA20（可用）否则 close
买入下限 = 中枢 - ATR × 0.5
买入上限 = 中枢 + ATR × 0.3
约束: 若 boll_lower < 买入下限，则下限 = boll_lower
约束: 买入上限不超过 close × 1.05
降级: ATR不可用 → close × 0.97 ~ close × 1.03
```

**目标价（无持仓）**：
```
目标价 = max(boll_upper, ma60)  若两者均可用
      = boll_upper              若仅 boll_upper
      = ma60                    若仅 ma60
约束: 目标价不低于 close × 1.05
降级: close × 1.10
```

**止损价（无持仓）**：
```
止损价 = 买入区间下限 - ATR × 1.0
降级: close × 0.95
```

**止盈价（有持仓）**：
```
止盈价 = cost_price × (1 + 目标涨幅%)
评级映射: 强烈推荐买入→+25%, 推荐买入→+20%, 持有观望→+12%, 建议减仓→+8%, 强烈建议卖出→+5%
约束: 止盈价不低于当前 close（若已超目标，建议止盈）
```

**止损价（有持仓）**：
```
止损价 = cost_price × (1 - 止损比例%)
评级映射: 强烈推荐买入→-8%, 推荐买入→-7%, 持有观望→-5%, 建议减仓→-4%, 强烈建议卖出→-3%
约束: 止损价不低于 close × 0.90
```

**仓位映射**：
```
强烈推荐买入(80+) → 80%
推荐买入(65-79)   → 50%
持有观望(50-64)   → 20%
建议减仓(30-49)   → 0%
强烈建议卖出(0-29) → 0%
```

#### 1.4 数据读取方式

price_advisor 需要读取以下数据：
1. **StockData**：通过 `from modules.data_adapter import load_stockdata_from_db` 获取 ma20/ma60/boll_upper/boll_lower/close
2. **raw_kline 最近15天 high/low/close**：直接查 DB 计算 ATR
3. **持仓信息**：从 `advice_result['has_position']` 和重新读 positions 表获取 cost_price

> 注意：advice_result 中已含 latest_close 和 has_position，优先从 advice_result 取，避免重复查询。
