## 一、三批次功能概述（供 QA 独立设计用例参考，不替代 QA 自行阅读代码）

### 批次 018 — 资金面数据源修复

**根因**：同花顺批量接口 `ak.stock_fund_flow_individual()` 返回的"净额"是全部资金净流入，非"主力净流入"口径，此前被错误写入 `main_net_inflow` 主字段。

| 文件 | 改动 |
|---|---|
| `modules/data_collector.py` | `fetch_capital_flow_batch()` 改为仅写 `ths_net_inflow` 辅助字段，不再写 `main_net_inflow`/`main_net_inflow_pct` |
| `database/db_manager.py` | `raw_capital_flow` 建表新增 `ths_net_inflow REAL` 列 + ALTER TABLE 兼容迁移 |
| `templates/index.html` | 资金面表格新增"同花顺净额（辅）"列 |
| `modules/daily_report.py` / `app.py` | 仅注释更新 |
| 数据清理 | 删除同花顺口径错误数据（`super_large_net IS NULL AND main_net_inflow IS NOT NULL`）+ 对应 data_status 记录 |

### 批次 019A — 评价一致性修复

**根因**：`generate_advice()` 只写 `analysis_results` + `ratings_history`，不写 `daily_reports`，导致三处展示入口评分不一致（如宁德时代 83.0 vs 61.9）。

| 文件 | 改动 |
|---|---|
| `modules/advisor.py` | 新增 `_save_daily_report_for_advice()` 函数（L592-L682），`generate_advice()` 末尾调用统一回写 `daily_reports`；已有日报时 UPDATE 保留 `markdown_content`/`price_advice`，无日报时 INSERT 新记录 |

### 批次 019B — 东财接口排查与重试机制

**根因**：东方财富 `push2his`/`push2`/`akshare` 三层接口对当前出口 IP 实施**间歇性反爬阻断**（`RemoteDisconnected`），非永久封禁/接口变更。

| 文件 | 改动 |
|---|---|
| `modules/data_collector.py` | `_http_get_em()`（L185-L248）增加多轮重试 + UA 池 + 随机延迟机制 |
| `scripts/` | 新增 11 个诊断脚本（`diag_em_019b.py` ~ `diag_verify_600519_019b.py`） |
| 恢复验证 | 贵州茅台(600519) 已通过周期性重试恢复 121 天历史主力净流入数据 |

详细背景见：`docs/tasks/dev_tasks_20260803_018_capital_source_fix.md` / `..._019A_rating_consistency.md` / `..._019B_eastmoney_api.md`；开发排查报告见 `reports/dev_diag_019B_em_failure_20260803.md`。
