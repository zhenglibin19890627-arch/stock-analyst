## 013 功能概述

新增"盘中快报"模式：
- 新 API：`POST /api/daily-report/generate-intraday`
- 生成 `report_type='intraday'` 的报告记录
- 盘中快报不覆盖已有正式日报（daily）
- 盘中快报之间可互相覆盖（仅保留最新一条 intraday）
- 盘后日报（`POST /api/daily-report/generate`）生成时删除当天 intraday，保存 daily 作为最终版
- 前端新增"盘中快报"按钮 + 报告类型徽标

### 涉及文件

| 文件 | 改动 |
|---|---|
| `database/db_manager.py` | 迁移函数：新增 report_type 列 + 唯一约束变更 |
| `modules/daily_report.py` | _save_report / _process_single_stock / generate_daily_report 增加 report_type |
| `app.py` | 新增 /api/daily-report/generate-intraday 端点 |
| `templates/index.html` | 盘中快报按钮 + JS + 徽标 |
