## 任务卡 1：FIX-ADJUST-UI 成本修正历史 UI 字段修复

| 字段 | 内容 |
|---|---|
| **任务ID** | FIX-ADJUST-UI |
| **优先级** | P0（Bug） |
| **需求映射** | §2.10 用户交互界面（界面功能正常展示） |
| **缺陷描述** | 前端 `loadAllAdjustments()` 期望字段 `original_avg_cost`/`adjusted_avg_cost`/`adjustment_reason`/`adjustment_notes`，但 API `/api/portfolio/cost-adjustments` 返回的数据库字段为 `old_cost`/`new_cost`/`reason`（无 notes 字段）。导致成本修正历史页面所有数据显示为 "—" |
| **核心动作** | 在 API 响应层做字段别名映射，使返回 JSON 与前端期望一致 |

### 技术方案

在 `app.py` 的 `api_get_all_cost_adjustments()` 函数中，对查询结果做字段映射：

```python
# 在 records = [dict(row) for row in cursor.fetchall()] 之后追加：
for rec in records:
    rec['original_avg_cost'] = rec.pop('old_cost', None)
    rec['adjusted_avg_cost'] = rec.pop('new_cost', None)
    rec['adjustment_reason'] = rec.pop('reason', None)
    rec['adjustment_notes'] = rec.get('operator_ip', '')  # 复用或留空
```

| 6 | 删除硬编码 | 移除 app.py `_INDUSTRY_MAP` 和 index.html `DASH_INDUSTRY_MAP`，改为从 API 返回的 industry 字段读取 |
| 7 | watchlist-scores 接口 | 直接从 stocks.industry 读取，不再查字典 |

#### A 股行业获取代码参考

```python
import akshare as ak


def fetch_stock_industry(symbol: str) -> str:
    """获取A股个股行业分类"""
    try:
        df = ak.stock_individual_info_em(symbol=symbol)
        row = df[df['item'] == '行业']
        if not row.empty:
            return str(row.iloc[0]['value'])
    except Exception:
        pass
    return '未分类'
```

#### 数据库迁移（幂等）

```python
# 在 db_manager.py init_database() 中追加：
cursor.execute('PRAGMA table_info(stocks)')
cols = {r['name'] for r in cursor.fetchall()}
if 'industry' not in cols:
    cursor.execute('ALTER TABLE stocks ADD COLUMN industry TEXT DEFAULT ""')
```

#### 前端适配

- 删除 `DASH_INDUSTRY_MAP` 硬编码字典
- 行业分布饼图改为读取 API 返回的 `st.industry` 字段（当前已有此逻辑，只是数据源从字典改为 DB）
- 行业筛选下拉框保持现有动态生成逻辑不变
