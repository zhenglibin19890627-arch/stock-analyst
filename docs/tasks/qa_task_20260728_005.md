## 三、验收测试用例

### TC1：无持仓股票价格建议（后端）

**前置条件**：选择一只无持仓的股票（如 stock_id=18 茅台 或 stock_id=27 海康）

**测试步骤**：
1. 调用 `generate_price_advice(stock_id, advice_result)` 或通过 `/api/stocks/<id>/advise` 端点
2. 检查返回的 `price_advice` 字段

**预期结果**：
- `available == true`
- `has_position == false`
- 包含字段：`position_pct`, `buy_range_low`, `buy_range_high`, `target_price`, `stop_loss`, `current_close`, `expected_gain_pct`, `max_loss_pct`, `disclaimer`
- `buy_range_low < buy_range_high`（买入区间下限 < 上限）
- `target_price > current_close`（目标价高于当前价）
- `stop_loss < current_close`（止损价低于当前价）
- `position_pct` 与评级匹配（推荐买入→50%）

### TC2：有持仓股票价格建议（后端）

**前置条件**：选择一只有持仓的股票（如 stock_id=7 汤臣倍健 cost=9.565）

**测试步骤**：
1. 调用 `/api/stocks/<id>/advise` 端点
2. 检查返回的 `price_advice` 字段

**预期结果**：
- `available == true`
- `has_position == true`
- 包含字段：`take_profit`, `stop_loss`, `cost_price`, `current_close`, `profit_pct`, `action_suggestion`, `disclaimer`
- `take_profit > cost_price`（止盈价高于成本价）
- `stop_loss < cost_price`（止损价低于成本价）

### TC3：数据不足场景（后端）

**测试步骤**：
1. 构造 `advice_result = {'latest_close': None, ...}` 的模拟数据
2. 调用 `generate_price_advice`

**预期结果**：
- `available == false`
- `reason` 包含描述信息

### TC4：API 端点集成验证

**测试步骤**：
1. `POST /api/stocks/18/advise` → 检查 JSON 含 `price_advice` 字段
2. `POST /api/stocks/27/analyze` → 检查 JSON 含 `price_advice` 字段
3. `GET /api/stocks/18/report-latest` → 检查 JSON 含 `price_advice` 字段（旧日报可能为 None）

**预期结果**：
- 三个端点返回 JSON 均包含 `price_advice` 字段
- 字段值结构正确

### TC5：日报持久化验证

**测试步骤**：
1. 手动触发日报生成（或检查已有日报）
2. 查询 `SELECT price_advice FROM daily_reports WHERE stock_id=18 ORDER BY report_date DESC LIMIT 1`

**预期结果**：
- 新日报的 `price_advice` 列有 JSON 值
- JSON 可正确解析为 dict
- 包含无持仓模式的完整字段
