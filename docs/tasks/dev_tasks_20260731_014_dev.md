## Bug 1：评级列表股票重复显示

### 现象

总览看板（`GET /api/ratings`）每只股票出现两次，57只显示成114行。

### 根因

`app.py` L1295-1306 的 SQL 查询：
```sql
WHERE dr.report_date = ? AND dr.status = 'ok'
```
未按 `report_type` 过滤。013 引入后同一天可能同时存在 daily + intraday 记录，导致重复。

### 修复方案

在 `/api/ratings` 端点中，应用与 `get_latest_reports()`（013-Hotfix）相同的优先逻辑：

```python
# 先查最新报告日期
cursor.execute('SELECT MAX(report_date) as latest_date FROM daily_reports')
date_row = cursor.fetchone()
latest_date = date_row['latest_date'] if date_row else None

# 014修复：优先取 daily，无 daily 时取 intraday
cursor.execute(
    "SELECT COUNT(*) as cnt FROM daily_reports WHERE report_date=? AND report_type='daily' AND status='ok'",
    (latest_date,),
)
has_daily = cursor.fetchone()['cnt'] > 0
target_type = 'daily' if has_daily else 'intraday'

# 在 WHERE 中增加 report_type 过滤
sql += ' AND dr.report_type = ?'
params.append(target_type)
```

### 影响范围

仅 `app.py` 的 `api_get_ratings_list()` 函数。

## Bug 2：个股详情持仓标签错误

### 现象

已持仓股票（如汤臣倍健，holdings 表有 1000 股）在详情页显示"仓位建议（当前无持仓）"。

### 根因

`advisor.py` L53-62 `_read_position()` **只查旧 `positions` 表**：
```python
cursor.execute('SELECT cost_price, quantity FROM positions WHERE stock_id = ?', (stock_id,))
```

而用户通过持仓管理页面添加的记录写入 `holdings` 表（新表）。`price_advisor.py` `_read_cost_price()` 已正确实现"优先 holdings，fallback positions"，但 `advisor.py` 未同步。

### 修复方案

修改 `advisor.py` L53-62 `_read_position()` 函数，采用与 `price_advisor.py` `_read_cost_price()` 相同的双表查询模式：

```python
def _read_position(stock_id):
    """读取持仓信息（014修复：优先 holdings 表，fallback positions 表）"""
    conn = get_connection()
    cursor = conn.cursor()

    # 优先查 holdings 表（新表，持仓管理页面写入）
    try:
        cursor.execute(
            "SELECT cost_price, quantity FROM holdings WHERE stock_id = ? AND status = 'active'",
            (stock_id,),
        )
        row = cursor.fetchone()
        if row and row['quantity'] and row['quantity'] > 0:
            conn.close()
            return {'cost_price': row['cost_price'], 'quantity': row['quantity']}
    except Exception:
        pass

    # Fallback: 旧 positions 表
    cursor.execute('SELECT cost_price, quantity FROM positions WHERE stock_id = ?', (stock_id,))
    row = cursor.fetchone()
    conn.close()
    if row and row['quantity'] and row['quantity'] > 0:
        return {'cost_price': row['cost_price'], 'quantity': row['quantity']}
    return None
```
