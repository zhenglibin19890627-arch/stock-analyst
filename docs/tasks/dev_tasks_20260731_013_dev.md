## 需求描述

### 用户故事

零代码用户在盘中（交易时段）打开系统，点击"盘中快报"按钮，系统基于当前数据生成分析结果。盘中快报**不覆盖**已有正式日报；盘后日报（18:00定时或手动触发）覆盖盘中快报，成为最终版本。

### 业务规则

| 场景 | 行为 |
|---|---|
| 盘中点击快报，当天无任何报告 | 生成 + 保存（report_type='intraday'） |
| 盘中再次点击快报（已有 intraday） | 生成 + 覆盖上一条 intraday |
| 盘中点击快报，当天已有 daily 报告 | 生成 + 保存为新 intraday 记录，**不动 daily** |
| 18:00 定时 / 手动盘后生成 | 生成 + 删除当天 intraday + 保存 daily（最终版） |

## 技术实现要求

### 1. 数据库迁移（db_manager.py）

**新增列**：`daily_reports` 表添加 `report_type TEXT DEFAULT 'daily'`

**变更唯一约束**：将 `UNIQUE(report_date, stock_id)` 改为 `UNIQUE(report_date, stock_id, report_type)`

实现方式：在 `_migrate_columns()` 之后新增迁移函数 `_migrate_daily_reports_type(cursor)`，采用 SQLite 标准表重建模式：

```python
def _migrate_daily_reports_type(cursor):
    """013: daily_reports 新增 report_type 列 + 变更唯一约束（幂等）"""
    # 检查是否已迁移（report_type 列存在则跳过）
    cursor.execute('PRAGMA table_info(daily_reports)')
    cols = [row[1] for row in cursor.fetchall()]
    if 'report_type' in cols:
        return
    # 表重建
    cursor.execute("""CREATE TABLE daily_reports_new (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        report_date DATE NOT NULL,
        stock_id INTEGER NOT NULL,
        stock_code TEXT,
        stock_name TEXT,
        engine_version TEXT,
        total_score REAL,
        rating TEXT,
        rating_label TEXT,
        prev_score REAL,
        score_change REAL,
        key_factors TEXT,
        data_warnings TEXT,
        status TEXT DEFAULT 'ok',
        error_msg TEXT,
        markdown_content TEXT,
        generated_at TEXT,
        price_advice TEXT,
        report_type TEXT DEFAULT 'daily',
        UNIQUE(report_date, stock_id, report_type),
        FOREIGN KEY (stock_id) REFERENCES stocks(id)
    )""")
    cursor.execute("""INSERT INTO daily_reports_new
        (id, report_date, stock_id, stock_code, stock_name, engine_version,
         total_score, rating, rating_label, prev_score, score_change,
         key_factors, data_warnings, status, error_msg, markdown_content,
         generated_at, price_advice, report_type)
        SELECT id, report_date, stock_id, stock_code, stock_name, engine_version,
               total_score, rating, rating_label, prev_score, score_change,
               key_factors, data_warnings, status, error_msg, markdown_content,
               generated_at, price_advice, 'daily'
        FROM daily_reports""")
    cursor.execute('DROP TABLE daily_reports')
    cursor.execute('ALTER TABLE daily_reports_new RENAME TO daily_reports')
    # 重建索引
    cursor.execute("""CREATE INDEX IF NOT EXISTS idx_daily_reports_date
        ON daily_reports(report_date)""")
```

在 `init_db()` 中 `_migrate_columns(cursor)` 调用之后调用此函数。

### 2. 保存逻辑修改（modules/daily_report.py）

**`_save_report()` 函数**增加 `report_type='daily'` 参数，保存逻辑改为：

```python
def _save_report(..., report_type='daily'):
    conn = get_connection()
    cursor = conn.cursor()
    generated_at = datetime.now(_CN_TZ).isoformat()

    if report_type == 'daily':
        # 盘后日报：删除当天该股票所有记录（含 intraday），插入新 daily
        cursor.execute(
            'DELETE FROM daily_reports WHERE report_date=? AND stock_id=?',
            (report_date, stock_id))
    else:
        # 盘中快报：仅删除之前的 intraday，不动 daily
        cursor.execute(
            "DELETE FROM daily_reports WHERE report_date=? AND stock_id=? AND report_type='intraday'",
            (report_date, stock_id))

    cursor.execute('''
        INSERT INTO daily_reports
            (report_date, stock_id, stock_code, stock_name, engine_version,
             total_score, rating, rating_label, prev_score, score_change,
             key_factors, data_warnings, status, error_msg, markdown_content,
             generated_at, price_advice, report_type)
        VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
    ''', (report_date, stock_id, stock_code, stock_name, engine_version,
          total_score, rating, rating_label, prev_score, score_change,
          json.dumps(key_factors, ensure_ascii=False) if key_factors else None,
          json.dumps(data_warnings, ensure_ascii=False) if data_warnings else None,
          status, error_msg, markdown_content, generated_at,
          json.dumps(price_advice, ensure_ascii=False) if price_advice else None,
          report_type))
    conn.commit()
    conn.close()
```

**注意**：移除原有 `ON CONFLICT ... DO UPDATE SET` 语句，改为 DELETE + INSERT 模式。

@app.route('/api/daily-report/generate-intraday', methods=['POST'])
def api_daily_report_generate_intraday():

### 6. 读取查询兼容

现有查询（`MAX(report_date)`、`report-latest`、评级列表等）**无需修改**：
- 盘后 daily 生成时会删除 intraday，最终只剩 daily
- 盘中若两者并存（先有 daily 后又生成 intraday），现有查询取到的可能是 intraday（因为同 report_date），这是可接受的（用户主动触发了更新的分析）

如需精确区分，可在 report-latest 等查询中增加 `ORDER BY CASE report_type WHEN 'daily' THEN 0 ELSE 1 END`，但**非必须**。
