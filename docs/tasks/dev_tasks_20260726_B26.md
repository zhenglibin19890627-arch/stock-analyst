### T1（P0）：两融采集函数增强

**文件**：`modules/data_collector.py`
**函数**：`fetch_margin_balance`（L1933-2045）及 `_fetch_margin_data_sse`（L1905）/`_fetch_margin_data_szse`（L1919）

**当前问题**：
1. `fetch_margin_balance` 仅尝试 T-1~T-5 共 5 天，且 `updated_count >= 2` 即 break，导致历史数据严重不足
2. `_fetch_margin_data_sse` 遇非交易日返回空 DataFrame（0行0列），akshare 内部抛出 `Length mismatch: Expected axis has 0 elements, new values have 13 elements` 异常，虽然被 try/except 捕获但导致该日期直接跳过

**修改要求**：

#### T1.1：扩大日期范围（fetch_margin_balance）
- 将 `for delta in range(1, 6)` 改为 `for delta in range(1, 35)`（覆盖最近30个交易日+周末）
- 将 `if updated_count >= 2: break` 改为 `if updated_count >= 30: break`（回填完整历史）
- 在循环外保留"非融资融券标的"判断（连续3个日期均无匹配才判定为非标的并跳过）

#### T1.2：非交易日异常容错（_fetch_margin_data_sse / _fetch_margin_data_szse）
- 在 `ak.stock_margin_detail_sse(date=date_str)` 和 `ak.stock_margin_detail_szse(date=date_str)` 调用后增加空 DataFrame 检查
- 捕获 `Length mismatch` / `ValueError` 等特定异常，记录 debug 日志后返回 None（当前已用通用 except 兜底，但需确保不会打印误导性的 warning）
- 缓存逻辑保持不变（已按日期缓存）

#### T1.3：列名匹配容错增强
- 当前列名匹配逻辑（L1981-1986）已可用（实测 sse 返回 `标的证券代码`/`融资余额`，szse 返回 `证券代码`/`融资余额`，均包含"代码"和"融资余额"关键词），**无需修改**
- 但需确认 `df[code_col].astype(str).str.zfill(6) == symbol` 匹配逻辑在 sse（代码为 int）和 szse（代码为 str）上均正确工作（实测已验证可用）

**红线**：不得修改 `data_collector.py` L1645/L1684/L1717 三处 `if False` 硬禁用。

```python
# --- 资金面 3 子项 ---
# B26：北向资金数据源自2024-08-16起停更（港交所政策变更），降权0.30→0.10
# 释放权重按主力:两融=45:25比例分配给主力(+0.10)和两融(+0.10)
CAPITAL_SUBITEMS: list[SubItem] = [
    SubItem(
        '主力资金',
        'main_capital',

        'keep_default',

    SubItem('互联互通', 'north_capital', ['north_net_buy'], 0.10, 'reduce'),
    SubItem('杠杆资金', 'margin_capital', ['margin_balance_chg'], 0.35, 'reduce'),

```

**权重变更对照**：

| 子项 | 原权重 | 新权重 | 变化 |
|---|---|---|---|
| 主力资金 | 0.45 | **0.55** | +0.10 |
| 互联互通(北向) | 0.30 | **0.10** | -0.20 |
| 杠杆资金(两融) | 0.25 | **0.35** | +0.10 |
| 合计 | 1.00 | **1.00** | — |

**影响分析**（Q03 归一化引擎自动处理）：
- 北向数据缺失时，reduce 降权 0.10×0.70=0.07，归一化后影响从原 25.1% 降至 ~8.1%
- 主力资金（keep_default）始终满权重，占比从 53.9% 升至 63.6%
- 两融数据回填后（T1完成），margin_capital 不再触发 reduce 降权，占满 35% 权重

### T3（P0）：两融历史数据回填执行

**新建文件**：`scripts/b26_margin_backfill.py`

**功能**：
1. 从 DB 读取所有 A 股自选股（market='a_stock'）
2. 对每只股票调用 `fetch_margin_balance(symbol, 'a_stock')`
3. 输出回填结果统计（成功/跳过/失败计数）
4. 回填完成后输出 margin_balance 填充率验证

**执行注意**：
- 两融接口（sse/szse）全市场数据较大（~2000行/次），每日期望延迟 1-2 秒
- 日期缓存（`_MARGIN_CACHE`）已内置，同一天不会重复请求
- 脚本需设置 `sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8', errors='replace')` 以防 Windows PowerShell 中文输出失败
