## OPT-2（P0）backups/ 备份保留策略

**背景**：`backups/` 已累积 **501 个文件、约 23MB**，无自动清理机制，将无限增长。备份是数据库操作的唯一安全网，策略须"保够不保多"。

**范围**：新增 `scripts/cleanup_backups.py`：
- 保留策略：**最近 30 天** 且 **至少保留 10 份**（两者取并集，防早期备份被清光）；
- 支持 `--dry-run`（默认）与 `--execute`，删除前列出清单；
- 可选：在 `start.bat` 启动尾部静默调用（`--execute`），不引入新常驻进程（零代码用户优先）。

**红线与约束**：只删 `backups/db_backup_*.db` 模式文件，**绝不触碰 `stock_analyst.db` 本体**；脚本内对 DB_PATH 做显式排除断言。

**验收**：
1. `--dry-run` 输出的删除清单正确（30 天外且超出保底份数）；
2. 单元测试覆盖"保留并集"边界（仿 `tests/` 现有风格，tmp_path 造 35 份假备份）；
3. 实际执行后 `stock_analyst.db` 与最近备份完好、服务健康检查 200。

**回滚**：删除脚本即回滚（已删备份不可恢复，故必须先 dry-run 人工确认）。

## OPT-5（P1）测试套件提速与 fast/full 分层

**背景**：2026-09-07 实测 `python -m pytest tests/` **超过 5 分钟未跑完**（超时终止）。全量套件过慢会压制"每次改动都跑测试"的执行率，且 OPT-3/OPT-4 两次大重构都依赖快速反馈。

**范围**：
1. `pytest --durations=25` 定位慢点（疑似 `test_data_collector.py` 970 行为主嫌疑）；
2. 慢测试归因分类：可隔离加速的（如重复建库、无谓 sleep）就地优化；本质慢的（历史回放类）打 `@pytest.mark.slow`；
3. `pyproject.toml` 注册 marker，默认 `addopts = -m "not slow"`；全量用 `pytest -m ""` 显式触发；
4. 引入 `pytest-timeout`（单测 60s 硬上限，防挂死）；同步更新 AGENTS.md §5 与 README 的验证命令说明。

**红线与约束**：只动测试基础设施，不改任何业务模块；`tests/conftest.py` 的隔离机制（MockDataProvider / 临时库）保持不变。

**验收**：
1. 默认 `python -m pytest tests/` **< 90 秒**（本机实测口径）；
2. `pytest -m ""` 全量仍可运行且全绿；
3. `check_redlines.py` 随 pytest 执行的行为不变。

**回滚**：git revert；marker 均为增量配置，无破坏面。

## OPT-4（P1）前端 app.js 按业务域拆分

## OPT-6（P2）应用层级联完整性测试补强

**背景**：SQLite `PRAGMA foreign_keys=OFF`，级联删除完全由应用层管理（`db_manager.get_connection` 约定）。42 张表的一致性目前依赖代码纪律 + 红线脚本看护，但**删除路径本身缺少系统化测试**——这是"改库结构时忘记同步级联"风险的最大兜底缺口。

**范围**：新增 `tests/test_cascade_integrity.py`：
- 覆盖全部删除端点触发的级联链：删自选股（stocks → kline/fundamental/capital/news/ratings/daily_reports/alerts…）、删分组（groups/stock_groups）、删账户（021W：holdings/trade_records 归入默认账户）、删持仓/流水（衍生表同步 + "安全锁"）；

**红线与约束**：只加测试不改实现；若测出真实级联缺口，**先登记到本文档"发现的问题"再另行立项**，不在本任务内顺手修。

**验收**：全部删除路径有测试且全绿；AGENTS.md §3"多行兼容约定"相关场景（同股多仓）纳入断言。

**回滚**：纯新增测试文件，revert 即可。

## OPT-7（P2）前端 CDN 依赖本地化

**背景**：`templates/index.html` 从 jsdelivr CDN 加载 `echarts@5.5.0` 与 `marked@12`。目标用户为零代码个人投资者，CDN 故障/网络异常时**图表与报告渲染直接不可用**，且无任何降级提示。

**范围**：下载两库至 `static/vendor/`（echarts.min.js ≈ 1MB、marked.min.js），index.html 改本地引用；`.gitignore` 不排除 vendor；下载动作与校验（SHA256）记录在本文档附注。

**红线与约束**：锁版本不升级（与现网行为一致）；体积增加约 1MB 属可接受（本地服务，无带宽顾虑）。

**验收**：断网（或屏蔽 jsdelivr）后启动服务，首页/报告图表/Markdown 渲染全部正常；`curl http://127.0.0.1:5000/` 200。

**回滚**：index.html 恢复 CDN 引用。
