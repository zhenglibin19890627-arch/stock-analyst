## 一、PM 调研结论

### 发现 1（BUG）：日报/看板评级颜色未生效

**根因：** CSS 类名不匹配。
- CSS 定义为 `.rating-strong-buy { ... }`（带 `rating-` 前缀）
- 但 `getRatingClass()` 函数返回 `'strong-buy'`（不带前缀）
- HTML 渲染为 `class="rating-badge strong-buy"`
- CSS 选择器 `.rating-strong-buy` 无法匹配 `class="strong-buy"`
- **结果：日报/看板的评级 badge 无颜色背景**

对比：自选股列表用 `ratingActionClass()` → `.action-buy` → CSS `.action-buy` 正确匹配，颜色正常。

### 发现 2：批量分析无进度反馈

**现状：**
- 点击"批量分析"后，仅显示静态文字"正在批量分析 X 只股票...预计耗时约 Y 秒"
- 单次 POST `/api/batch-analyze` 等待全部完成才返回
- 20 只股票约需 5 分钟，用户无任何进度感知

**已有条件：**
- 单股分析 API 已存在：`POST /api/stocks/<id>/analyze`
- 前端可逐只调用 + 更新进度条，**无需后端改动**

### 发现 3：术语对零代码用户不友好

页面中"四维评分"、"技术面"、"基本面"、"资金面"、"消息面"、"T+1"、"评级有效性"等术语无解释。

### T1：修复日报/看板评级颜色（BUG，5分钟）

**修改文件：** `templates/index.html`

**方案（二选一，推荐 A）：**

**A. 修改 `getRatingClass()` 返回值（1行）：**
```javascript
// 修改前（L5008）：
return 'rating-' + (map[rating] || 'hold');

// 修改后：去掉多余的 'rating-' 前缀，直接返回完整 CSS 类名
return 'rating-' + (map[rating] || 'hold');
```

等等，实际上 CSS 类名就是 `.rating-strong-buy`，而函数返回 `'rating-strong-buy'`...

让我重新分析：HTML 是 `class="rating-badge ' + getRatingClass(r.rating) + '"`，即 `class="rating-badge rating-strong-buy"`。CSS 是 `.rating-strong-buy { ... }`。这应该匹配！

**重新核验：** 如果 CSS 和类名实际匹配，那问题可能是 CSS 特异性（specificity）被其他规则覆盖，或者 `.rating-badge` 基础样式覆盖了背景色。

**开发需先核验：** 在浏览器 DevTools 中检查日报评级 badge 元素，确认：
1. 实际渲染的 class 属性值
2. CSS 是否被应用（是否被划掉）
3. 是否有其他规则覆盖

**修复方向：**
- 如果是 specificity 问题：提高 `.rating-strong-buy` 的选择器权重
- 如果是类名问题：修正 `getRatingClass()` 或 CSS 定义
- 确保 5 档评级在日报/看板/回测 3 个页面均有颜色区分

### T2：批量分析进度条（核心体验提升）

**修改文件：** `templates/index.html`（仅前端）

**方案：** 将 `batchAnalyze()` 从"单次 POST 等全部完成"改为"逐只调用 + 实时进度"：

```javascript
function batchAnalyze() {
    var ids = [];
    document.querySelectorAll('.stock-cb:checked').forEach(function(cb) { ids.push(parseInt(cb.value)); });
    if (ids.length === 0) { alert('请先勾选要分析的股票'); return; }

    var area = document.getElementById('collectArea');
    var total = ids.length;
    var done = 0;
    var results = [];

    // 渲染进度条
    area.innerHTML = '<div class="card"><div class="card-title">⚡ 批量分析与评级</div>' +
        '<div id="batchProgress" style="margin:16px 0;">' +
        '<div style="background:#e0e0e0;border-radius:8px;height:24px;overflow:hidden;">' +
        '<div id="batchBar" style="background:#4caf50;height:100%;width:0%;transition:width 0.3s;border-radius:8px;"></div>' +
        '</div>' +
        '<p id="batchStatus" style="margin-top:8px;font-size:14px;color:#555;">准备中...</p>' +
        '</div><div id="batchResults"></div></div>';
    area.scrollIntoView({ behavior: 'smooth' });

    // 逐只分析
    function processNext(idx) {
        if (idx >= total) { finishBatch(); return; }
        var stockId = ids[idx];
        document.getElementById('batchStatus').textContent =
            '正在分析第 ' + (idx+1) + '/' + total + ' 只股票 (ID:' + stockId + ')...';
        document.getElementById('batchBar').style.width = Math.round(idx/total*100) + '%';

        fetch('/api/stocks/' + stockId + '/analyze', { method: 'POST' })
            .then(function(r) { return r.json(); })
            .then(function(data) {
                results.push(data);
                done++;
                document.getElementById('batchBar').style.width = Math.round(done/total*100) + '%';
                processNext(idx + 1);
            })
            .catch(function(err) {
                results.push({ success: false, stock_id: stockId, message: String(err) });
                done++;
                processNext(idx + 1);
            });
    }

    function finishBatch() {
        document.getElementById('batchBar').style.width = '100%';
        document.getElementById('batchStatus').textContent =
            '✅ 全部完成！成功 ' + results.filter(r=>r.success).length + '/' + total;
        // 渲染结果表格（复用 renderBatchResults 逻辑）
        renderBatchResults({ success: true, total: total,
            success_count: results.filter(r=>r.success).length,
            results: results.map(function(r) {
                return { symbol: r.stock_code, name: r.stock_name, status: r.success?'completed':'failed',
                         rating: r.rating, total_score: r.total_score,
                         operation_suggestion: r.operation_suggestion, error: r.message,
                         rating_time: r.rating_date };
            })
        }, ((Date.now() - startTime) / 1000).toFixed(1));
        loadRatings();
    }

    var startTime = Date.now();
    processNext(0);
}
```

**关键约束：**
- 不修改后端 API（零代码用户无需重启）
- 复用已有 `/api/stocks/<id>/analyze` 端点
- 进度条实时显示当前第几只 / 共几只
- 单只失败不阻塞后续
- 完成后自动刷新评级列表

**验收标准：**
- [ ] 批量分析时显示绿色进度条 + "正在分析第 X/Y 只"
- [ ] 进度条随每只完成实时推进
- [ ] 单只失败不中断整体流程
- [ ] 完成后显示结果表格（与现有格式一致）
- [ ] 评级列表自动刷新
