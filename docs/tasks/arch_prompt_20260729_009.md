## 问题实例（中国中免 stock_id=21）

```
当前价：55.40
成本价：60.78（浮亏 -8.9%）
止盈价：72.94（需涨 31.6%）
止损价：56.53（当前价已跌破！）
操作建议：加仓20%（当前价<止损价，建议加仓=逻辑矛盾）
```

### 四大核心问题

| # | 问题 | 说明 |
|---|---|---|
| 1 | 跌破止损仍建议加仓 | 操作建议不检查当前价与止损/止盈线位置关系 |
| 2 | 止盈价不参考市场状态 | 止盈价=成本价*固定系数(+20%)，不结合技术面阻力位 |
| 3 | 缺少网格价位 | 只给一个止盈/止损价，无分批建仓/减仓阶梯 |
| 4 | 资金面未转化为操作建议 | '主力净流入21800万'只是展示文字，未影响建议 |

### 额外需求：交易流水分析

用户希望参考其买卖操作记录(trade_records)给出更精准建议。

## 当前算法现状

### price_advisor.py 有持仓算法（L249-263）

```python
# 止盈价 = 成本价 * (1 + 目标涨幅)
take_profit = cost_price * (1 + target_gain)  # 推荐买入->固定+20%

# 止损价 = 成本价 * (1 - 止损比例)
stop_loss = cost_price * (1 - stop_loss_pct)  # 推荐买入->固定-7%

# 操作建议 = 固定文本映射
action_suggestion = RATING_ACTION_SUGGESTION[rating]  # '加仓20%'
```

## 架构评审决策点（7项，详见任务书）

1. **操作建议状态机**：当前价与止损/止盈/成本价的关系 -> 动态操作建议
2. **止盈价动态化**：参考技术面阻力位（MA60/布林上轨）而非纯固定系数
3. **网格价位设计**：分批建仓/减仓的阶梯价位算法
4. **资金面转化**：主力流入/流出趋势如何修改操作建议
5. **交易流水分析**：trade_records 的利用方案
6. **前端展示**：网格表格设计
7. **影响面分析**：涉及哪些文件
