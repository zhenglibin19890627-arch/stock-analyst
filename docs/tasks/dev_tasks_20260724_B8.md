## 架构设计要点

### 核心思路：复用现有评分引擎

现有 `scoring_engine.analyze()` 已原生支持维度缺失时的权重自动归一化：
- 指数无基本面/消息面数据 → 这两维 score=None → 自动排除
- 权重自动归一化到 kline（+ capital_flow 如有）
- **无需修改 scoring_engine.py 核心逻辑**

### 数据流

```
akshare 指数K线 → 技术指标计算(MA/MACD/KDJ/RSI/BOLL) → 构造 StockData → scoring_engine.analyze() → 评级结果 → 存入 index_ratings 表 → API → 前端看板
```

### 技术方案

#### 评级流程

```python
from modules.data_contract import StockData
from modules.scoring_engine import analyze


def score_index(index_info: dict) -> dict:
    """对单只指数执行评级"""
    # 1. 从 index_kline 读取最近 250 天K线
    # 2. 计算技术指标（MA/MACD/KDJ/RSI/BOLL/量比）
    # 3. 构造 StockData（仅填充技术面字段，基本面/消息面留 None）
    data = StockData(
        code=f'{index_info["code"]}.IDX',
        market='A' if index_info['market'] == 'A' else 'HK',
        trade_date=latest_date,
        close=latest_close,
        ma5=...,
        ma10=...,
        ma20=...,
        ma60=...,
        macd_dif=...,
        macd_dea=...,
        kdj_k=...,
        rsi_14=...,
        volume=...,
        volume_ratio=...,
        boll_upper=...,
        boll_lower=...,
        # 基本面/消息面/资金面全部 None → 引擎自动排除
    )
    # 4. 调用评分引擎
    result = analyze(data)
    # 5. 存入 index_ratings 表
    return result
```

#### 权重处理

- 指数仅有 kline 维度可用时，权重自动归一化为 kline=100%
- 如后续接入指数资金流向数据，可补充 capital_flow 维度
- 初始方案：纯技术面评级（kline=100%），后续可扩展

#### 批量评级入口

```python
def score_all_indices() -> list[dict]:
    """批量评级所有指数，返回结果列表"""
    results = []
    for idx in INDEX_LIST:
        try:
            r = score_index(idx)
            results.append(r)
        except Exception as e:
            logger.warning(f'指数评级失败 {idx["name"]}: {e}')
            results.append({'index_code': idx['code'], 'name': idx['name'], 'error': str(e)})
    return results
```

## 任务卡 3：INDEX-API 指数评级 API 接口

| 字段 | 内容 |

| **需求映射** | §2.11.3 展示位置 |

### 技术方案

#### API 设计

| 接口 | 方法 | 功能 |
|---|---|---|
| `/api/index-ratings` | GET | 获取所有指数最新评级（从 index_ratings 表读取） |
| `/api/index-ratings/refresh` | POST | 触发指数数据采集 + 重新评级 |

#### `/api/index-ratings` 响应格式

```json
{
  "success": true,
  "indices": [
    {
      "code": "000001",
      "name": "上证指数",
      "market": "A",
      "trade_date": "2026-07-24",
      "close": 3250.12,
      "pct_change": 0.85,
      "total_score": 62.3,
      "rating": "持有观望",
      "kline_score": 62.3
    }
  ],
  "updated_at": "2026-07-24 18:00:00"
}
```

#### `/api/index-ratings/refresh` 逻辑

1. 调用 `index_collector.fetch_all_index_kline()` 更新K线
2. 调用 `index_collector.score_all_indices()` 重新评级
3. 返回最新评级结果

#### 自动刷新策略

- 批量分析（`/api/batch-analyze`）执行时，顺带刷新指数评级（异步，不阻塞主流程）
- 或在 daily_report 生成时顺带触发
