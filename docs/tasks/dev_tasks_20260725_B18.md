## 一、背景与问题陈述

### 1.1 现状数据（2026-07-25 实测）

| 指标 | 数值 | 说明 |
|---|---|---|
| 最新评分区间 | 34.4 ~ 63.3 | 全部 27 只股票 |
| 最新评级分布 | 持有观望 17 + 建议减仓 10 | 无推荐买入/强烈推荐买入 |
| 历史评分分布（173条） | 70+ 仅 3 条（1.7%），85+ 为 0 | 区分度严重不足 |
| 四维均分 | 技术面 59.4 / 基本面 47.8 / 资金面 42.9 / 消息面 65.0 | 资金面严重偏低 |

### 1.2 根因分析

B16 报告已识别根因 2：评分区间过窄。经 PM 实测数据验证，问题出在**各子项评分函数的基准值和映射曲线**：

| 维度 | 问题 | 影响 |
|---|---|---|
| **资金面** | 主力净流入中性值 0 万 → 60 分；北向/两融缺失 → 50 分；加权后 avg=42.9 | 拖累总分 3~5 分 |
| **基本面** | ROE/毛利率/成长性阈值偏严，avg=47.8 | 好股票难突破 60 |
| **技术面** | 均线/趋势/超买超卖基准 50 起步，avg=59.4 | 上限 76.4 尚可但下限 33.3 过低 |
| **消息面** | 情绪映射 (sentiment+1)*50，avg=65.0 | 偏高，进一步压缩其他维度权重效果 |

**加权后总分被压缩在 30~65 区间，无法达到 70（推荐买入阈值）。**

### 1.3 需求基线映射

- §2.2.1 四维分析引擎：评分应具有区分度，能有效分层
- §2.3.1 五档评级：85/70/50/30 边界，当前 70+ 几乎不存在，评级体系名存实亡
- §6 验收标准：评级分布应覆盖五档，而非仅两档

## 二、任务目标

**校准四维评分引擎的子项评分函数，使评分分布恢复区分度：**

1. 最新一期评分中，至少 20% 股票达到 70+（推荐买入）
2. 评分区间拉开至 20~85（而非当前 34~63）
3. 四维均分回归合理区间（50~65），避免单一维度严重拖累
4. 不改变 rating_mapping 五档阈值（85/70/50/30 红线不变）

---

## 三、任务卡

### T1（P0）：资金面评分函数校准

**问题**：资金面 avg=42.9，严重偏低。主力净流入 0 万 → 60 分（中性），但 A 股多数股票日常净流出 → 45 分以下；北向/两融缺失 → 50 分（keep_default），加权后进一步拉低。

**修改文件**：`modules/scoring_engine.py`

**具体修改**：

| 子项 | 函数 | 修改内容 |
|---|---|---|
| 主力资金 | `score_main_capital` | 中性基准从 60→65；小幅净流入(0~1000万) 从 60→68；温和净流入(1000~5000万) 从 75→80；大幅净流入(>5000万) 从 90→92 |
| 互联互通 | `score_north_capital` | 缺失默认值从 50→55（中性偏暖）；小幅买入(0~500万) 从 58→62 |
| 杠杆资金 | `score_margin_capital` | 缺失默认值从 50→55；小幅增加(0~500万) 从 58→62 |

**预期效果**：资金面 avg 从 42.9 → 48~52

---

### T2（P0）：基本面评分函数校准

**问题**：基本面 avg=47.8，ROE/毛利率/成长性阈值偏严，好股票难突破 60。

**修改文件**：`modules/scoring_engine.py`

**具体修改**：

| 子项 | 函数 | 修改内容 |
|---|---|---|
| 估值 | `score_valuation` | PE≤15 从 90→92；PE≤25 从 75→78；PB≤1 从 85→88 |
| 盈利能力 | `score_profitability` | ROE≥20 从 95→96；ROE≥15 从 82→85；ROE≥10 从 65→70；毛利率≥50 从 90→92；毛利率≥30 从 72→76 |
| 成长性 | `score_growth` | 营收≥30% 从 95→96；营收≥20% 从 80→83；营收≥10% 从 65→70；净利≥50% 从 95→96；净利≥30% 从 82→85；净利≥15% 从 68→72 |
| 现金流质量 | `score_cashflow` | OCF≥1.2 从 90→92；OCF≥0.8 从 80→83 |
| 财务健康度 | `score_fin_health` | 资产负债率≤30% 从 90→92；流动比率≥2.0 从 85→88 |

**预期效果**：基本面 avg 从 47.8 → 52~56

---

### T3（P0）：技术面评分函数校准

**问题**：技术面 avg=59.4，上限 76.4 尚可但下限 33.3 过低，且部分子项基准 50 起步压缩了上限。

**修改文件**：`modules/scoring_engine.py`

**具体修改**：

| 子项 | 函数 | 修改内容 |
|---|---|---|
| 均线 | `score_ma` | 金叉基准从 70→75；价格在均线之上加分从 +2→+3（每条） |
| 趋势 | `score_trend` | MACD 多头基准从 65→70；价格在 60 日均线上方加分上限从 15→18 |
| 超买超卖 | `score_obos` | RSI 健康区域(45~65) 基准从 80→82；KDJ 健康区域(40~60) 从 75→78 |
| 量价分析 | `score_vol_price` | 成交量≥2000万 从 75→78；500~2000万 从 65→68 |
| 波动率 | `score_volatility` | 布林带位置 40~70% 从 78→80 |

**预期效果**：技术面 avg 从 59.4 → 62~66，上限突破 80

---

### T4（P1）：消息面评分函数微调

**问题**：消息面 avg=65.0，偏高，压缩了其他维度权重效果。

**修改文件**：`modules/scoring_engine.py`

**具体修改**：

| 子项 | 函数 | 修改内容 |
|---|---|---|
| 情绪 | `score_sentiment` | 映射曲线从 (sentiment+1)*50 → (sentiment+1)*48（轻微压缩上限）；显著正面(>0.3) 时上限从 100→95 |
| 股东行为 | `score_holder` | 增持从 80→82（鼓励信号） |

**预期效果**：消息面 avg 从 65.0 → 60~63

---

### T5（P1）：校准后验证脚本

**任务**：开发一个验证脚本 `scripts/calibrate_verify.py`（或 `_b18_verify.py`），用于：

1. 对全部 27 只自选股执行最新评分
2. 输出评分分布直方图（0-29/30-49/50-69/70-84/85+）
3. 输出四维均分 + 总分均分
4. 对比校准前后差异（从 ratings_history 读取旧数据）

**验收标准**：
- 70+ 股票占比 ≥ 20%（当前 0%）
- 评分区间 ≥ 40 分跨度（当前 34.4~63.3 = 28.9 分）
- 四维均分在 50~65 区间
