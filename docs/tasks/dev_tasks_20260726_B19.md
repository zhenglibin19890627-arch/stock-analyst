## 二、根因分析（PM 纯只读诊断已完成）

### 根因定位

**代码位置**：`modules/advisor.py` L448
```python
score_date = analysis.get('score_date', rating_time[:10])
```
- v5 引擎返回的 `score_date` = K线最新交易日（如周五 07-24）
- daily_reports 的 `report_date` = 当天日期（如周日 07-26）
- 非交易日时，analysis_results 写入 `analysis_date=07-24`，daily_reports 写入 `report_date=07-26`，日期不对齐

### 影响范围

| 接口 | 数据源 | 影响 |
|---|---|---|
| `/api/ratings` | daily_reports ✅ | 已统一（B11-SCORE-SYNC） |
| `/api/stocks/<id>/report-latest` | daily_reports ✅ | 已统一 |
| `/api/stocks/<id>/analysis` | analysis_results ⚠️ | 日期与日报不对齐 |
| `optimizer_engine.analyze_dimension_accuracy` | analysis_results ⚠️ | JOIN 时 analysis_date 与 rating_date 可能不匹配 |

## 三、技术方案

### 修改点1（核心）：generate_advice 增加 report_date 参数

**文件**：`modules/advisor.py`

- L651 `def generate_advice(stock_id):` → `def generate_advice(stock_id, report_date=None):`
- L677 `_save_analysis_results_for_v5(stock_id, analysis, '')` → `_save_analysis_results_for_v5(stock_id, analysis, '', report_date=report_date)`

### 修改点2：_save_analysis_results_for_v5 支持 report_date 覆盖

**文件**：`modules/advisor.py` L439

- L439 `def _save_analysis_results_for_v5(stock_id, analysis, operation_suggestion=''):` → 增加参数 `report_date=None`
- L448 `score_date = analysis.get('score_date', rating_time[:10])` → 增加逻辑：
  ```python
  if report_date:
      score_date = report_date
  else:
      score_date = analysis.get('score_date', rating_time[:10])
  ```
  即：有 report_date 时优先使用（保证与日报同日），无则回退到原逻辑（兼容单只分析场景）。

### 修改点3：daily_report.py 调用 generate_advice 时传入 target_date

**文件**：`modules/daily_report.py` L444

- `advice = generate_advice(stock_id)` → `advice = generate_advice(stock_id, report_date=target_date)`
