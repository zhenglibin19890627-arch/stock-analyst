2. 修改 `fetch_stock_industry()` 的回退逻辑：

```python
def fetch_stock_industry(symbol: str, market: str = 'a_stock') -> str:
    """获取个股行业分类。
    A股：优先 akshare API，失败时使用本地映射兜底。
    港股：默认返回"港股"。
    """
    if market == 'hk_stock' or symbol.upper().startswith('HK'):
        return '港股'
    # 优先尝试 API
    try:
        df = ak.stock_individual_info_em(symbol=symbol)
        if df is not None and not df.empty:
            row = df[df['item'] == '行业']
            if not row.empty:
                val = str(row.iloc[0]['value']).strip()
                if val:
                    return val
    except Exception as e:
        logger.warning(f'[{symbol}] 行业API失败，尝试本地映射: {e}')
    # B14: API 失败时兜底本地映射
    local = _LOCAL_INDUSTRY_MAP.get(symbol)
    if local:
        return local
    return '未分类'
```

**验收标准：**
- [ ] `fetch_stock_industry('600519')` 在 API 失败时返回 `'酿酒行业'`（非"未分类"）
- [ ] `fetch_stock_industry('000333')` 在 API 失败时返回 `'家电行业'`
- [ ] `fetch_stock_industry('HK9988', 'hk_stock')` 返回 `'港股'`（不受影响）
- [ ] 不在字典中的新股票，API 失败时仍返回 `'未分类'`

### T2：启动时自动补全已有"未分类"记录

**修改文件：** `database/db_manager.py`（`init_db()` 末尾添加迁移）

**方案：**
在 `init_db()` 末尾添加幂等迁移：

```python
# B14: 行业本地映射补全（幂等）
try:
    from modules.data_collector import _LOCAL_INDUSTRY_MAP

    for symbol, industry in _LOCAL_INDUSTRY_MAP.items():
        cursor.execute(
            """
            UPDATE stocks SET industry = ?
            WHERE symbol = ? AND (industry IS NULL OR industry = '未分类' OR industry = '')
        """,
            (industry, symbol),
        )
    if cursor.rowcount > 0:
        print(f'[B14迁移] 行业映射补全完成')
except Exception as e:
    print(f'[B14迁移] 行业补全警告: {e}')
```

**验收标准：**
- [ ] 启动 `python app.py` 后，22 只 A 股的 industry 字段自动补全
- [ ] `SELECT COUNT(*) FROM stocks WHERE industry='未分类' AND market='a_stock'` = 0
- [ ] 已有正确 industry 的记录不被覆盖（幂等）
- [ ] 重复启动不报错
