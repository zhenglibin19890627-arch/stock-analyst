## 任务1：重写 modules/price_advisor.py（~500行）

### 1.1 操作建议状态机（修复核心Bug）

新增函数 `_determine_action_by_state(close, cost_price, take_profit, stop_loss, rating)`

状态定义（有持仓）：
- S1: close >= take_profit -> '已超目标'
- S2: cost_price < close < take_profit -> '浮盈中'
- S3: stop_loss <= close <= cost_price -> '浮亏中'
- S4: close < stop_loss -> '已破止损'

状态x评级操作建议矩阵（5x4=20种组合），核心规则：
**S4（已破止损）的操作建议必须包含'止损'或'清仓'，禁止出现'加仓'**

详细矩阵见架构师报告§1.2。

无持仓场景也需感知价位（详见任务书§1.1）。

### 1.2 止盈价动态化

方案C 双约束公式：
```
固定止盈价 = cost_price * (1 + target_gain)
技术阻力位 = _calc_resistance(close, ma60, boll_upper)
最低止盈价 = cost_price * (1 + min_target_gain)
止盈价 = max(最低止盈价, min(固定止盈价, 技术阻力位))
```

新增常量：
```python
MIN_TARGET_GAIN = {
    '强烈推荐买入': 0.08,
    '推荐买入': 0.06,
    '持有观望': 0.04,
    '建议减仓': 0.03,
    '强烈建议卖出': 0.02,
}
```

新增函数 `_calc_resistance(close, ma60, boll_upper)`：
- 取 boll_upper 和 ma60 中 > close 的最小值（最近阻力位）
- 都不可用时降级为 close * 1.10

### 1.3 网格价位

新增函数 `_build_grid(close, buy_range_low, buy_range_high, atr, cost_price, take_profit, stop_loss, rating, has_position)`

无持仓买入网格（3档）：
```
档位1: price=buy_range_low, pct=40, type='buy', label='第一买入位'
档位2: price=buy_range_low+ATR*0.8, pct=35, type='buy', label='第二买入位'
档位3: price=buy_range_high, pct=25, type='buy', label='第三买入位'
```

有持仓网格（1补+3减）：
```
档位1: price=max(stop_loss+ATR*0.5, close-ATR*1.0), pct=10, type='add', label='补仓位'
档位2: price=cost_price, pct=30, type='reduce', label='回本减仓位'
档位3: price=cost_price+ATR*0.6, pct=50, type='reduce', label='第一止盈位'
档位4: price=take_profit, pct=100, type='reduce', label='最终止盈位'
```

### 1.4 资金面转化

资金面因子来源：`advice_result['dimensions']['capital_flow']['factors']`

需解析的文本格式（正则提取数字）：
- 'main_trend': '主力净流入21800万元' -> 21800
- 'consecutive': '连续净流入2日' -> +2, '连续净流出3日' -> -3
- 'super_large': '超大单净8000万元(流入)' -> +8000

新增函数：
- `_parse_capital_factors(factors)`: 文本解析为结构化数据
- `_classify_capital_signal(parsed)`: 分类7档信号(-2~+2)

修饰词方案：
- 强流入(+2): 前置 '资金面强支撑，'
- 中流入(+1): 前置 '资金面偏积极，'
- 弱流入(+0.5): 后置 '，资金面略有流入'
- 中性(0): 不修饰
- 弱流出(-0.5): 后置 '，注意资金面略有流出'
- 中流出(-1): 前置 '资金面偏弱，'
- 强流出(-2): 前置 '资金面明显流出，'
- 超大单异常: 追加风险提示

输出结构：
```python
'capital_signal': {'strength': 2, 'label': '强流入', 'modifier': '资金面强支撑，', 'risk_warning': None}
```

### 1.5 交易流水分析

新增函数 `_analyze_trade_records(stock_id)`：

从 trade_records 表读取（SQL: SELECT * FROM trade_records WHERE stock_id=? ORDER BY trade_date）

3个分析维度：
- 维度1 加仓节奏：买入间隔天数（<=3天=频繁加仓/追涨风险, <=10天=分批建仓, >10天=低频）
- 维度2 成本趋势：模拟每次加仓后的成本价（递减=好/递增=差）
- 维度3 买卖时机：FIFO配对买卖，计算胜率和平均盈亏

降级：买入记录<2笔时 available=False

输出结构：
```python
'trade_analysis': {'available': True, 'trade_count': 9, 'rhythm': {...}, 'cost_trend': {...}, 'timing': {...}, 'summary': '一句话摘要'}
```
