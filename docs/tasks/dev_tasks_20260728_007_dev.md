## 三、开发任务详细分解

### 任务1：新建 modules/price_backtest.py（~400行）

#### 核心函数清单

1. _calc_historical_indicators(stock_id, end_date) — 截取end_date之前的K线，计算MA20/MA60/BOLL/ATR
2. _calc_historical_atr(stock_id, end_date, period=14) — 历史时点ATR计算
3. _gen_price_advice_at_date(stock_id, end_date) — 在指定日期生成价格建议（复用price_advisor算法逻辑，不import修改）
4. _check_hit(kline_slice, advice) — 基于日内high/low判定命中
5. run_price_backtest(market, force) — 主回测函数（遍历所有股票，每5天一个回测点）
6. compute_price_backtest_report(market) — 生成回测报告（命中率/时间效率/偏差/分组/综合）

详细算法和命中定义见方案设计报告和开发人员提示词。

### 任务2：修改 database/db_manager.py — 新建表（+40行）

在 init_database() 函数索引区域（L527附近）之前追加 price_backtest_results 表。
表结构含：stock_id/backtest_date/rating/market + 价格建议输出 + 技术指标快照 + T5/T20命中结果。
详见开发人员提示词中的完整SQL。

### 任务3：修改 app.py — 新增2个API端点（+30行）

- POST /api/price-backtest/run — 触发回测（参数：market, force）
- GET /api/price-backtest/report — 获取回测报告（参数：market）

### 任务4：修改 templates/index.html — 前端展示（+50行）

在回测报告页面'分级准确率'表格之后，新增'价格建议命中率'section。
展示：买入区间命中率/目标价命中率/止损价命中率/风险收益比 + T+5 vs T+20对比表。
