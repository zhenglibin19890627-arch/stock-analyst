## 技术方案（产品经理指定）

### 方案选型（零代码用户最高优先级）

| 格式 | 方案 | 理由 |
|---|---|---|
| **Excel** | 服务端 `openpyxl` 生成 .xlsx，浏览器触发下载 | 用户双击即可打开（WPS/Excel），最友好 |
| **PDF** | 浏览器 Ctrl+P 打印为 PDF + 打印友好 CSS | **零额外依赖**，用户无需安装任何软件 |

### 新增依赖

| 包名 | 版本 | 用途 | 安装方式 |
|---|---|---|---|
| `openpyxl` | >=3.1.0 | Excel 文件生成 | 加入 `requirements.txt`，`pip install -r requirements.txt` 一键安装 |

> 仅此 1 个新依赖。PDF 方案零依赖（利用浏览器原生打印）。

## 功能规格

### 1. Excel 导出（3 个导出点）

#### 1.1 每日报告导出

| 项目 | 内容 |
|---|---|
| **触发位置** | 日报页面「导出Excel」按钮 |
| **API** | `GET /api/export/daily-report?date=2026-07-22` |
| **文件内容** | Sheet1「概览」：股票/代码/总分/评级/较昨日涨跌；Sheet2「详情」：每只股票四维得分/数据完整度/操作建议/风险提示 |
| **文件名** | `StockAnalyst_日报_2026-07-22.xlsx` |

#### 1.2 自选股总览导出

| 项目 | 内容 |
|---|---|
| **触发位置** | 看板页面「导出Excel」按钮 |
| **API** | `GET /api/export/watchlist` |
| **文件内容** | Sheet1「自选股」：股票/代码/市场/分组/最新评级/总分/今日涨跌/持仓成本/盈亏；Sheet2「资金流向」：主力净流入/北向/融资余额 |
| **文件名** | `StockAnalyst_自选股_2026-07-22.xlsx` |

#### 1.3 回测报告导出

| 项目 | 内容 |
|---|---|
| **触发位置** | 回测中心页面「导出Excel」按钮 |
| **API** | `GET /api/export/backtest?market=a_stock` |
| **文件内容** | Sheet1「市场报告」：总体准确率/分级准确率/周期准确率；Sheet2「个股明细」：每条评级的T+1/T+5/T+20收益与判定 |
| **文件名** | `StockAnalyst_回测_A股_2026-07-22.xlsx` |

### 2. PDF 导出（浏览器打印）

| 项目 | 内容 |
|---|---|
| **触发方式** | 页面「导出PDF」按钮 → 调用 `window.print()` |
| **技术实现** | 添加 `@media print` CSS 规则：隐藏导航栏/按钮，优化表格排版，分页控制 |
| **适用范围** | 日报页面、个股报告页面、看板页面、回测中心 |
| **用户体验** | 点击按钮 → 弹出系统打印对话框 → 选择「另存为PDF」→ 保存 |

### 3. UI 交互设计

| 位置 | 新增元素 |
|---|---|
| 日报页面顶部 | 「导出Excel」「导出PDF」两个按钮 |
| 看板页面顶部 | 「导出Excel」「导出PDF」两个按钮 |
| 回测中心顶部 | 「导出Excel」「导出PDF」两个按钮 |
| 个股报告页面 | 「导出PDF」按钮（个股数据量小，Excel 意义不大） |

**按钮样式**：沿用现有 UI 风格，图标 + 文字（如 📥 导出Excel / 🖨️ 导出PDF）
