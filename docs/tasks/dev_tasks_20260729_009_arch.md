## 一、需求背景

005 价格建议上线后，用户实际使用中发现 4 个核心问题（以中国中免 stock_id=21 为例）：

### 问题实例（中国中免）

```
当前价：55.40
成本价：60.78（浮亏 -8.9%）
止盈价：72.94（需涨 31.6%）
止损价：56.53（当前价已跌破！）
操作建议：加仓20%（当前价<止损价，建议加仓=逻辑矛盾）
```

### 四大核心问题

| # | 问题 | 严重度 | 说明 |
|---|---|---|---|
| 1 | **跌破止损仍建议加仓** | Bug | 操作建议不检查当前价与止损/止盈线的位置关系 |
| 2 | **止盈价不参考市场状态** | 体验 | 止盈价=成本价*固定系数，不结合技术面阻力位 |
| 3 | **缺少网格价位** | 增强 | 只给一个止盈/止损价，无分批建仓/减仓阶梯 |
| 4 | **资金面未转化为操作建议** | 增强 | 资金面数据（主力流入/流出）只展示，未影响建议 |

### 额外需求：交易流水分析

用户希望系统参考其**交易流水**（trade_records 表中的买卖操作记录），给出更精准的操作建议。

## 四、架构评审决策点

### 决策点1：操作建议状态机（问题1）

当前操作建议是固定文本映射（评级->固定文本），需要改为**基于当前价位的动态状态机**：

| 当前价位置 | 推荐买入评级应有的建议 |
|---|---|
| close > 止盈价 | '已超目标，建议止盈' |
| 成本价 < close < 止盈价 | '持有，等待止盈' |
| 止损价 < close < 成本价 | '浮亏中，持有观望' |
| close < 止损价 | '已破止损，建议止损/观望反弹' |

架构师需设计完整的状态机（5 档评级 x 多种价位关系）。

### 决策点2：止盈价动态化（问题2）

当前止盈价=成本价*固定系数，需改为**参考技术面阻力位**：

| 候选方案 | 说明 |
|---|---|
| A | 止盈价 = min(成本价*(1+目标涨幅), 技术面阻力位) |
| B | 止盈价 = 技术面阻力位（MA60/布林上轨/前高）|
| C | 给出多个止盈阶梯（如第一目标/第二目标）|

架构师需推荐方案并给出具体公式。

### 决策点3：网格价位设计（问题3）

需要设计分批建仓/减仓的阶梯价位：

```
示例（无持仓，推荐买入）：
第一买入位：55.00（仓位30%）
第二买入位：52.00（仓位20%）
目标价：65.00
止损价：49.00

示例（有持仓，当前浮亏）：
补仓位：53.00（仓位10%）
减仓位（反弹至）：62.00（减仓30%）
止损价：50.00
```

架构师需设计网格的间距算法（基于ATR还是固定百分比）和分档数量。

### 决策点4：资金面趋势转化为操作建议（问题4）

当前资金面因子已有（main_trend/consecutive/main_pct/super_large），需设计如何影响操作建议：

| 资金面信号 | 对操作建议的影响 |
|---|---|
| 主力连续净流入3日+ | 操作建议偏积极（如'加仓'->'可加仓'）|
| 主力连续净流出3日+ | 操作建议偏保守（如'持有'->'考虑减仓'）|
| 超大单大幅流出 | 风险提示加强 |

架构师需设计资金面因子如何修改基础操作建议（覆盖/加权/附加提示）。

### 决策点5：交易流水分析

需要设计如何利用 trade_records 表的买卖记录增强建议：

| 分析维度 | 说明 |
|---|---|
| 加仓节奏 | 用户是否频繁加仓（追涨）或分批建仓 |
| 摊薄成本 | 加仓后成本价变化趋势 |
| 买卖时机 | 历史买卖点的盈亏统计 |

架构师需评估：trade_records 数据是否充足？分析输出什么格式？是否新建模块？

### 决策点6：前端展示改动

价格建议 section 需要从'单值表格'升级为'网格表格'：
- 无持仓：展示多档买入位+目标价+止损价
- 有持仓：展示补仓位+减仓位+止损价+资金面提示
- 交易流水摘要（可选）

### 决策点7：影响面分析

需评估涉及哪些文件修改、改动范围。
