## 一、背景

监理反馈：多只股票主力净流入未获取到，仅宁德时代有数据。

### 诊断数据

- 系统中23只A股，仅宁德时代（300750）有 `main_net_inflow`（东财数据）
- 其余22只A股均无 `main_net_inflow`，仅有 `ths_net_inflow`（同花顺辅助数据）
- `data_status` 表显示：自2026-07-22起，东方财富接口大面积失败（push2his/push2/akshare三层降级全部失败）
- 宁德时代在2026-08-03 20:27手动采集成功（唯一成功案例）

### 失败原因（data_status记录）

```
东方财富接口全部失败（push2his/push2/akshare）。
估算数据源（新浪/腾讯/网易）已禁用，不再写入估算值作为真实数据。
```

## 三、排查范围

### Step 1：测试东财接口当前状态

直接调用东方财富 push2his 接口，测试至少5只股票：

```
GET https://push2his.eastmoney.com/api/qt/stock/fflow/daykline/get
参数：lmt=0&klt=101&secid={market}.{code}&fields1=f1,f2,f3,f7&fields2=f51,f52,f53,f54,f55,f56
```

测试股票：300750（宁德时代）、600519（贵州茅台）、000333（美的集团）、002415（海康威视）、601888（中国中免）

确认：是个别股票失败还是全面失败？

### Step 2：排查失败原因

如果接口仍失败，逐项排查：

1. **请求头检查**：User-Agent、Referer 是否被反爬识别
2. **代理配置**：检查系统代理是否失效
3. **接口地址**：确认 push2his.eastmoney.com 是否可访问
4. **频率限制**：是否因请求频率过高被封IP

### Step 3：评估替代方案

如果东财接口短期无法恢复：

1. 是否有其他可用的主力资金流向数据源？
2. 备用数据源的数据质量是否可接受？
3. 是否需要临时启用估算数据源（新浪/腾讯/网易）作为兜底？
