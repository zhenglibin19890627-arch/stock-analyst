## 二、现状分析（PM 纯只读诊断已完成）

### news_sentiment 表 vs StockData 映射

| DB 字段 | 含义 | 有值率 | StockData 映射 | 计入完整度 |
|---|---|---|---|---|
| avg_sentiment | 情绪指数(-1~1) | ✅ 100% | ✅ news_sentiment | ✅ |
| positive_count | 正面新闻数 | ✅ 100% | ❌ **未映射** | ❌ |
| negative_count | 负面新闻数 | ✅ 100% | ❌ **未映射** | ❌ |
| total_count | 新闻总数 | ✅ 100% | ❌ **未映射** | ❌ |
| top_news_title | 头条标题 | ✅ 100% | ❌ **未映射**（文本不适合完整度计算） | ❌ |
| holder_increase | 股东增减持 | ❌ ~0%（低频） | ✅ holder_increase | ✅（拖累完整度） |

### 完整度计算现状（data_contract.py L218-228）

```python
NEWS = {'news_sentiment', 'holder_increase'}  # 只有2个字段
news_total = 2
news_present = 2 - len(self.missing_fields('news'))
# news_sentiment 有值 + holder_increase 无值 = 1/2 = 50%
```

### 修改点5：data_adapter.py — 从 news_sentiment 表映射新字段

**文件**：`modules/data_adapter.py` L377-382（消息面映射区域）

```python
# 修改前：

if news:
    avg_sent = news.get('avg_sentiment')
    if avg_sent is not None:
        news_sentiment = float(avg_sent)

# 修改后：
news_sentiment = None
news_count = None
news_positive_ratio = None
news_negative_count = None
if news:
    avg_sent = news.get('avg_sentiment')
    if avg_sent is not None:
        news_sentiment = float(avg_sent)
    # B22: 扩展消息面字段
    total = news.get('total_count')
    pos = news.get('positive_count')
    neg = news.get('negative_count')
    if total is not None and total > 0:
        news_count = int(total)
        news_negative_count = int(neg) if neg is not None else 0
        if pos is not None:
            news_positive_ratio = round(pos / total, 2)
```
