#### 算法实现（严格按架构师评审报告）

**1. ATR 计算（Average True Range）**

raw_kline 表含 high/low/close 字段（已确认）。

```
TR（真实波幅）= max(high - low, |high - prev_close|, |low - prev_close|)
ATR(14) = TR 的 14 日简单移动平均
```

SQL 取数：
```sql
SELECT high, low, close FROM raw_kline
WHERE stock_id=? ORDER BY trade_date DESC LIMIT 15
```

降级：raw_kline 不足15天用已有天数；不足2天 → ATR 不可用，降级为固定百分比。

**2. 买入价位区间（无持仓）**

```
买入中枢 = MA20（若可用）否则 close
买入下限 = 中枢 - ATR × 0.5
买入上限 = 中枢 + ATR × 0.3
约束1: 若 boll_lower 可用且 < 买入下限 → 下限 = boll_lower
约束2: 买入上限不超过 close × 1.05（避免追高）
降级: ATR不可用 → close × 0.97 ~ close × 1.03
```

**3. 目标价（无持仓）**

```
目标价 = max(boll_upper, ma60)  若两者均可用
      = boll_upper              若仅 boll_upper
      = ma60                    若仅 ma60
约束: 目标价不低于 close × 1.05（至少5%空间才有买入价值）
降级: close × 1.10（固定10%目标）
```

**4. 止损价（无持仓）**

```
止损价 = 买入区间下限 - ATR × 1.0
降级: close × 0.95（固定-5%）
```

**5. 止盈价（有持仓）**

```
止盈价 = cost_price × (1 + 目标涨幅%)
```

评级→目标涨幅映射：

| 评级 | 目标涨幅 |
|---|---|
| 强烈推荐买入 | +25% |
| 推荐买入 | +20% |
| 持有观望 | +12% |
| 建议减仓 | +8% |
| 强烈建议卖出 | +5% |

约束：止盈价不低于当前 close（若已浮盈超过目标，建议止盈）。

**6. 止损价（有持仓）**

```
止损价 = cost_price × (1 - 止损比例%)
```

评级→止损比例映射：

| 评级 | 止损比例 |
|---|---|
| 强烈推荐买入 | -8% |
| 推荐买入 | -7% |
| 持有观望 | -5% |
| 建议减仓 | -4% |
| 强烈建议卖出 | -3% |

约束：止损价不低于 close × 0.90（最大亏损不超过10%）。

**7. 仓位映射（无持仓时建议仓位）**

| 评级 | 总分区间 | 建议仓位 |
|---|---|---|
| 强烈推荐买入 | 80+ | 80% |
| 推荐买入 | 65-79 | 50% |
| 持有观望 | 50-64 | 20% |
| 建议减仓 | 30-49 | 0% |
| 强烈建议卖出 | 0-29 | 0% |

#### 数据读取方式

1. **StockData**：通过 `from modules.data_adapter import load_stockdata_from_db` 获取 ma20/ma60/boll_upper/boll_lower/close
2. **raw_kline 最近15天 high/low/close**：直接查 DB 计算 ATR
3. **持仓信息**：从 `advice_result['has_position']` 判断；有持仓时读 positions 表 cost_price
4. **评级**：从 `advice_result['rating']` 获取

> 注意：advice_result 中已含 latest_close 和 has_position，优先从 advice_result 取，避免重复查询。
