## 二、根因分析（PM 纯只读诊断已完成）

### 根因1：PE/PB 写入正确但残留于旧行（0% 填充率）

**现象**：DB 中 PE 非空行=1行/股，但 `MAX(report_date)` 行（adapter 读取行）PE 为 NULL。

**根因链**：
```
fetch_a_fundamental → INSERT 4行财报（含 roe/net_margin 等，无 PE/PB）
腾讯估值 PE/PB → UPDATE 到当时的 MAX(report_date) 行
后续 force 重跑 → fetch_a_fundamental 再次 INSERT/REPLACE →
  新行的 report_date 可能与 PE/PB 合并的行不同 → PE/PB 残留在旧行
fetch_fundamental_detail → UPDATE WHERE stock_id=?（全行更新 NULL 字段，不影响 PE/PB）
```

**关键代码位置**：
- `data_collector.py` L551-568：PE/PB UPDATE 用 `WHERE report_date = (SELECT MAX(report_date)...)`
- `data_adapter.py` L370-380：读取用 `ORDER BY report_date DESC LIMIT 1`（取最新 report_date 行）

**修复方向**：PE/PB UPDATE 后，或 adapter 读取时，确保 PE/PB 在 adapter 读取的行中。

### 根因2：holder_increase 写入逻辑正常但执行条件不满足

**现象**：DB 中 holder_increase 全部为 NULL。

**根因**：`_save_holder_increase`（L726-745）UPDATE 到 `MAX(report_date)` 行，但和 PE/PB 同样的"行错位"问题。此外 `fetch_holder_increase`（L663）依赖雪球接口 `stock_inner_trade_xq()`，可能返回 None（无近期增减持记录或接口不稳定）。

## 三、修复方案

### 方案1（P0）：data_adapter.py — 聚合读取解决行错位

**核心思路**：不强依赖单行，改为从 `raw_fundamental` 中**聚合读取**最新有效值。

**文件**：`modules/data_adapter.py` L370-390

修改前（取最新行单条记录）：
```python
fund = cursor.execute(
    'SELECT * FROM raw_fundamental WHERE stock_id=? ORDER BY report_date DESC LIMIT 1', ...
).fetchone()
```

修改后（聚合读取：各字段取最新非 NULL 值）：
```python
# 对 pe_ratio/pb_ratio/holder_increase 做 COALESCE 聚合：
# 优先取最新 report_date 行的值，为 NULL 则回退到次新行
fund = cursor.execute(
    """
    SELECT * FROM raw_fundamental WHERE stock_id=? 
    ORDER BY report_date DESC LIMIT 1
""",
    ...,
).fetchone()

# 补充：如果最新行 PE/PB 为 NULL，从其他行取
if fund and (fund['pe_ratio'] is None or fund['pb_ratio'] is None):
    pe_row = cursor.execute(
        """
        SELECT pe_ratio, pb_ratio FROM raw_fundamental 
        WHERE stock_id=? AND (pe_ratio IS NOT NULL OR pb_ratio IS NOT NULL)
        ORDER BY report_date DESC LIMIT 1
    """,
        ...,
    ).fetchone()
    if pe_row:
        fund = dict(fund)  # 转可变 dict
        if fund.get('pe_ratio') is None:
            fund['pe_ratio'] = pe_row['pe_ratio']
        if fund.get('pb_ratio') is None:
            fund['pb_ratio'] = pe_row['pb_ratio']

# 同理处理 holder_increase
if fund and fund.get('holder_increase') is None:
    hi_row = cursor.execute(
        """
        SELECT holder_increase FROM raw_fundamental 
        WHERE stock_id=? AND holder_increase IS NOT NULL
        ORDER BY report_date DESC LIMIT 1
    """,
        ...,
    ).fetchone()
    if hi_row:
        fund['holder_increase'] = hi_row['holder_increase']
```

### 方案2（备选）：data_collector.py — PE/PB 合并改为更新所有行

将 L562-564 的 UPDATE 从单行改为 WHERE stock_id（更新所有行的 PE/PB），确保任何行读取时都有值。

**PM 建议采用方案1**（改 data_adapter.py，不动 data_collector.py 的采集逻辑），因为：
- 影响面更小（只改读取逻辑）
- 不改变采集行为（避免引入新的写入副作用）
- 符合红线约束（data_collector.py 改动风险更高）
