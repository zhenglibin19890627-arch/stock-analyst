## 一、改动概述

**唯一改动文件**：`modules/daily_report.py`

| 改动 | 位置 | 内容 |
|---|---|---|
| 核心逻辑 | L529-584 | 单只超时控制：`with ThreadPoolExecutor + future.result(timeout=90)` 块 → daemon 线程 `threading.Thread(daemon=True) + t.join(timeout=STOCK_TIMEOUT_SECONDS)` + `is_alive()` 超时分支 |
| M-1 清理（可选已执行） | L27-28 删除 | `from concurrent.futures import ThreadPoolExecutor` / `TimeoutError as FuturesTimeout`（修复后未使用） |

**实现要点**：
- **box 模式**：线程内异常显式捕获存 `box['exc']`，超时后重抛走外层 except（线程异常不自动传播）
- **超时分支**：`t.is_alive()` → failed 记录（error_msg=`采集超时(90s)`）+ results.append + `continue`，**不 join 不等待 worker**（红线 10）
- **worker 迟到自愈保留**：超时后后台 daemon 线程继续，`_process_single_stock` 内部 `_save_report`（DELETE+INSERT）覆盖 failed→ok（红线 7）
- **禁止 `with ThreadPoolExecutor`**（M-1 红线）：架构师对照实验实证 with 块退出 `shutdown(wait=True)` join 挂死线程，修复无效
