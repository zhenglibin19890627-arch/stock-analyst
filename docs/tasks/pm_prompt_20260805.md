## 九、019H/019I 批次经验教训

1. **019H 教训**：监理要求"生成架构师任务书"时，PM 只签发 `dev_tasks_..._arch.md` 供监理在独立窗口启动架构师，PM **不得**自行以架构师身份执行评审并产出 review 文档。如已越权产出，须坦诚声明并降级为"初步评审待架构师复核"。
2. **019I 教训（M-1 红线）**：`with ThreadPoolExecutor` 块退出时 `__exit__` 调用 `shutdown(wait=True)` 会 join 挂死 worker 线程——任何"超时保护"若用 with 块实现均属无效修复。经架构师运行时实验 + PM 独立复现确认。正确模式：daemon 线程 `Thread(daemon=True) + t.join(timeout=N)`，超时后立即返回且不阻塞进程退出。**daily_report.py L533 现存同款缺陷（R-3），下一批次修复时严禁复制该模式。**
