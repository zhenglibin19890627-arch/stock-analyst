## 二、问题描述

**现状**：22 只 A 股 industry 字段全部为 `"未分类"`，批量分析时无法触发自动补取。

**根因**：`app.py` 批量分析接口中，补取条件为：
```python
if not (stock['industry'] or '').strip():
```
添加股票时 `fetch_stock_industry()` 失败会写入 `"未分类"`（非空字符串），导致此条件永远为 False，补取逻辑永远不执行。

---

## 三、技术方案

### 修改点（仅 1 处）

**文件**：`app.py` 批量分析接口（约 L1004）

**修改前**：
```python
if not (stock['industry'] or '').strip():
```

**修改后**：
```python
if not (stock['industry'] or '').strip() or stock['industry'] in ('未分类',):
```

### 设计要点

1. 仅修改判断条件，不改变 `fetch_stock_industry()` 函数本身
2. 港股仍返回 `"港股"`（无免费行业接口，设计如此，不改）
3. 补取失败仍静默 pass，不阻塞分析流程（保持现有容错）
4. 不引入新依赖、不增加配置步骤
