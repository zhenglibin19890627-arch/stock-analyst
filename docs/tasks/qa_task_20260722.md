## 任务A（P0）：数据修复后的质量核验

架构师正在排查资金面3.8%和经典引擎全0分的根因，修复后将交QA独立核验。请提前设计数据质量测试用例：

| # | 测试项 | 达标标准 |
|---|---|---|
| 1 | capital 维度采集成功率 | ≥95%（26只中≥25只success） |
| 2 | HK3690 fundamental 状态 | = success（连续3日） |
| 3 | 经典引擎股票是否仍有0分 | 全部0分股票修复后应有真实评分 |
| 4 | 四维数据完整度 | 各维度有数据时日报须展示，不得全空 |
| 5 | 无估算值污染 | 三处 if False 估算源未恢复 |

### 核验方法

```sql
-- capital 成功率
SELECT dimension, COUNT(*) as total,
  SUM(CASE WHEN status='success' THEN 1 ELSE 0 END) as success,
  ROUND(SUM(CASE WHEN status='success' THEN 1 ELSE 0 END)*100.0/COUNT(*),1) as rate
FROM data_status WHERE date(fetched_at)=date('now','localtime')
GROUP BY dimension;

-- 0分股票检查
SELECT s.symbol, s.name, ar.total_score, ar.rating
FROM analysis_results ar
JOIN stocks s ON ar.stock_id = s.id
WHERE ar.total_score = 0;
```
