## 二、方案定稿过程

### 2.1 PM原始方案（O2-A/B/C/D）
PM基于根因分析（001）提出4个优化方案，经架构师独立评审：

| 方案 | 评审意见 | PM态度 | 说明 |
|---|---|---|---|
| O2-A | 建议修改 | ✅接受 | 追加中性分提升，比改极端档更有效 |
| O2-B | 同意 | ✅接受 | 方向正确 |
| O2-C | 否决 | ✅接受 | PM对score_profitability逻辑误判，当前代码已正确处理gross_margin缺失 |
| O2-D | 否决 | ✅接受 | 茅台07-27已反弹至+9491万(95分)，5日平滑反而降到60分；全表0只被拯救 |
| **O2-E** | **推荐** | ✅采纳 | 降资金面权重0.40→0.30，升基本面0.20→0.25，直击本质 |

### 2.2 监理追加洞察
监理提出"是否自选股本身不够优质"，PM数据验证：
- 自选股80%基本面"一般及以下"（ROE普遍2-11%，多只营收负增长）
- 但更关键：优质股（如茅台ROE10%/PE19.5）被资金面短期波动拖累至55.8分
- 结论：评分校准仍需做，O2-E（降资金面权重）正是治本之策
